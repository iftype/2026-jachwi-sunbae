# 랜딩과 비로그인 동네 탐색

## 로컬 확인

작업 브랜치: `feat/370-landing-exploration-login`. 기존 서비스 화면과 별개로 공개 탐색 화면을 제공한다.

- `/`: 비로그인 방문자는 `/landing`으로 이동, 로그인 사용자는 매물 목록으로 이동한다.
- `/landing`: 비로그인 방문자는 랜딩, 로그인 사용자는 매물 목록. 랜딩에는 서비스 이름·강조한 한 줄 설명·펼쳐진 움직이는 사용 시연·`동네 찾아보기` 버튼과 바로 로그인 화면으로 가는 `이미 기록 중이라면 로그인하기` 링크를 표시한다. 로그인 링크는 비로그인 상태에서만 보이며 클릭 이벤트는 `destination: login`으로 수집한다. 하단 앱·웹 보조 버튼은 표시하지 않는다. 헤더 위에는 앱 안내 높이의 공간을 항상 확보한다. 모바일에서만 화면 상단에 `앱으로 써보기` 안내를 표시하고 PC에서는 같은 자리를 빈 공간으로 유지한다. 기기 안전 영역은 유지한다. 안드로이드는 Google Play(`com.jachwisunbae`), 아이폰·아이패드는 App Store로 연결한다. 앱 버튼 클릭 이벤트는 `app_store`와 `google_play`로 구분한다. `동네 찾아보기`에는 hover 강조 효과를 제공하며 움직임 줄이기 설정을 따른다. 별도 제목/사용법 목록/개인정보 링크는 표시하지 않는다. 시연 하단의 가상 정보 안내와 재생 버튼은 일반 화면에서 숨긴다. 키보드로 포커스했을 때만 재생 제어 버튼을 표시하고 움직임 줄이기 설정은 유지한다.
- `/explore`: 통근 시간 / 월세 평균가 탐색 선택.
- `/about`: 같은 소개·시연을 로그인 여부와 무관하게 볼 수 있는 별도 주소. 마이 메뉴에서 접근한다. 탐색 선택 화면의 소개·사용 안내 다시 보기 링크는 제거한다.
- `/explore/commute`, `/explore/price`: 하단 서비스 탭 없는 공개 지도. 검색 또는 지도 선택 후 조건으로 조회.
- 결과의 `이 동네에서 본 방 기록하기`: 로그인 화면으로 이동한다. 로그인 후에는 경로와 관계없이 매물 목록으로 이동하며 등록 폼으로 바로 보내지 않는다.
- 통근 결과에서 동네를 골라도 출발 정류장은 지도 마커로 찍지 않는다. 정류장은 대중교통 상세의 출발 정류장 선택지에서만 보여준다.

프론트엔드에서 `PORT=3000 USE_REAL_COMMUTE_API=false POSTHOG_PROJECT_TOKEN='' npm run dev:mock`으로 실행한다. 로컬 시안은 MSW 응답이며 외부 PostHog에 전송하지 않는다. 기존 `/neighborhoods` 경로는 유지한다.

최신 develop에서 공개된 통근·월세·지도 주소 API를 사용한다. 인증을 우회하거나 가짜 토큰을 생성하지 않는다.

MSW 실행도 자동 로그인하지 않는다. 기록 버튼에서 로그인 화면으로 이동해 닉네임을 입력하면 기존 `POST /api/auth/nickname` 목 응답으로 로그인한다. 실제 로그인으로 저장된 세션은 새로고침 시 유지하지만, 로그아웃한 세션을 MSW가 다시 생성하지 않는다. 이전 자동 로그인 토큰이 남아 있다면 한 번 로그아웃하고 확인한다. 같은 출처의 다른 탭에도 로그아웃을 반영한다.

## 첫 진입과 지도 사용 안내

서비스 전체 흐름은 랜딩에서 자동 시연으로 소개한다. 기능 선택 화면의 서비스 소개 오버레이는 제거했다. 지도 조작 안내는 유지하며, 동네 탐색은 공개로, 실제 기록 저장은 로그인 후 제공한다. `/about` 조회는 `service_introduction_viewed`, 실제 랜딩 조회는 `landing_page_viewed`로 구분한다.

뒤로가기나 같은 탭 새로고침에서는 목적지·필터·선택 동네/정류장 코드를 sessionStorage에 30분 동안 보관해 복원한다. API/목 데이터 설정 및 공개/서비스 경로별로 분리한다. 경계와 API 응답은 저장하지 않고 Query Cache를 재사용하거나 조건으로 다시 조회한다. 다시 선택하기를 누르면 저장 조건도 초기화한다. 저장 정보가 없거나 만료된 상세 주소는 오류 안내 화면 대신 위치 선택 지도로 이동한다.

공개 통근/월세 지도에 처음 진입하면 검색창·필터 아래 작은 말풍선으로 위치 선택 → 조건 선택 → 찾기를 안내한다. 화면 전체를 가리거나 조작을 막지 않는다. 위치를 고르면 조건 안내로, 필터에서 적용하거나 `지금 조건으로 할게요`를 누르면 찾기 안내로 바뀐다. 필터 시트가 열리거나 검색 결과를 고르는 동안 말풍선은 숨긴다.

`안내 건너뛰기` 또는 조회 시작 시 해당 모드의 안내 상태를 localStorage에 저장한다. 같은 브라우저에서는 다시 표시하지 않으며, 통근/월세는 별도로 기억한다. 저장소가 차단되면 이번 방문 동안만 닫힌 상태를 유지한다. 저장 키는 `jachwi.exploration-tutorial.v1.commute`, `jachwi.exploration-tutorial.v1.price`이다.

`exploration_tutorial_viewed`, `exploration_tutorial_skipped`, `exploration_tutorial_completed`로 안내 지표를 별도 수집한다. 안내 완료는 찾기 버튼 클릭 기준이며 API 조회 성공인 `exploration_completed`와 다르다.

## 전환 이벤트

| 이벤트                           | 발생 기준                             |
| -------------------------------- | ------------------------------------- |
| `landing_page_viewed`            | 랜딩 진입                             |
| `exploration_started`            | 위치를 정하고 조건으로 찾기를 누름    |
| `exploration_completed`          | 조회 성공, 빈 결과도 결과 개수와 기록 |
| `exploration_record_cta_clicked` | 조회 완료 후 방 기록 버튼 클릭        |
| `exploration_login_completed`    | 위 버튼 이후 실제 닉네임 로그인 성공  |
| `exploration_record_form_viewed` | 위 흐름에서 매물 등록 화면 진입       |
| `exploration_property_saved`     | 위 등록 폼의 실제 저장 API 성공       |

공개 탐색 이벤트에 `journey_id`, `exploration_mode`, `source: landing`, `mock_data`를 함께 보낸다. 주소·좌표·닉네임은 이벤트에 넣지 않는다. 선택 위치는 로그인 이후 이어가기 위해 현재 탭의 sessionStorage에 보관하고 30분 후 무효화한다. 저장소가 차단되면 기록 전환은 현재 탭 메모리만 사용하며, 지도 재진입 복원은 지원하지 않는다.

PostHog에서는 단순 이벤트 발생 횟수가 아니라 고유 방문자 기반 퍼널로 본다. `mock_data: true`는 운영 지표에서 제외한다.

- 기능 사용 전환율: 랜딩 방문자 중 `exploration_started` 방문자 비율.
- 기능 완료율: 탐색 시작 방문자 중 `exploration_completed` 방문자 비율. 빈 결과는 `result_count`로 별도 구분.
- 서비스 진입 전환율: 탐색 완료 방문자 중 `exploration_record_form_viewed` 방문자 비율.
- 기록 저장 전환율: 탐색 완료 방문자 중 `exploration_property_saved` 방문자 비율.

로그인은 전환의 중간 단계이며, 버튼 클릭이나 폼 진입을 실제 기록 저장으로 집계하지 않는다. 로그인 후 등록 폼으로 자동 이동하지 않으므로 `exploration_record_form_viewed`와 `exploration_property_saved`는 현재 흐름에서 발생하지 않는다. 대시보드/퍼널 설정은 별도이며 이 시안은 이벤트 발생 지점만 제공한다.
