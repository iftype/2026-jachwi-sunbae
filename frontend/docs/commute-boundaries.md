# 통근 지도 행정동 경계

통근 탐색 결과의 행정동 경계를 어떻게 나눠 배포하고, 받아서, 지도에 그리는지 정리한다. 배포 절차는 [프론트엔드 배포](deployment.md#행정동-경계-자산)를 참고한다.

## 지도 표시 정책

- 동네 찾기는 위치 선택·분석·결과 단계에서 지도 하나를 계속 쓴다. 분석 중·실패 화면은 지도를 없애지 않고 위에 덮는다. 결과마다 지도를 새로 만들면 네이버 GL이 스타일·타일·글꼴을 처음부터 다시 준비해서, 검색 뒤 경계가 다 그려지기까지 시간의 절반 이상을 차지했다.
- 행정동 경계는 폴리곤마다 하나만 그린다. 별도의 광택용 중복 경계는 만들지 않는다.
- 동네 선택에는 기존 경계를 재사용하고 선택·호버 스타일만 변경한다. 좌표가 바뀐 동만 교체하고, 사라진 동과 지도 종료 시 리스너·오버레이를 정리한다. 다중 폴리곤과 내부 링은 유지한다.
- 새 결과는 가까운 시간대(`drawStage` 0 → 1 → 2) 순서로, GL 지도 준비가 끝난 뒤 프레임마다 최대 40개 동씩 등록한다. 같은 단계 안에서는 그 시점 지도 중심에 가까운 동부터 넣는다. GL 준비 전에 넣은 도형은 SDK가 로드 순간 한꺼번에 등록하기 때문이다. 준비 여부는 SDK 내부 플래그로 확인하며, 신호가 없어도 3초가 지나면 그린다. 선택·호버·확대 단계 변경은 나누지 않고 바로 반영한다.

## 시도별 경계 분할

- 전국 원본은 계속 `data/admin-dongs.geojson` 하나로 관리한다. Webpack 빌드에서 SGIS 행정동 코드 앞 두 자리(시도)마다 파일을 하나씩 생성한다. 예: 서울 `11`, 인천 `23`, 경기 `31`. 좌표·내부 링·속성은 바꾸지 않는다. 가격 탐색의 법정동 파일은 별도이며 변경하지 않는다.
- `manifest.json`의 `files`에 시도 코드를 키로 `admin-dongs.<시도>.<기준일>.<해시>.geojson` 파일명을 기록한다. 원본 다운로드 없이 앱 시작 시 자동 다운로드되지도 않는다.
- 통근 API 결과와 manifest를 병렬로 받은 뒤, **목적지 위치가 아닌 결과 행정동 코드**에 필요한 파일만 병렬 다운로드하고 합친다. 빈 결과는 경계 파일을 요청하지 않는다. 인천 동이 섞이면 인천 파일(gzip 약 270KB)만 추가로 받는다. manifest에 없는 시도 코드가 섞이면 경계 누락 대신 전국 파일을 받는다.
- 파일별 Query 캐시를 공유하므로 같은 파일은 재조회에 재사용하고 파일 해시가 바뀌면 새 파일을 받는다. 다운로드 실패를 누락된 경계로 감추지 않는다.
- 배포 전환 호환성을 위해 기존 `manifest.file`과 전국 파일도 산출한다. 새 앱은 분할 정보가 없는 구 manifest를 받으면 기존 전국 파일을 사용한다. manifest에 분할 정보가 있지만 잘못된 경로·기준일이면 오류로 처리한다.
- 배포 시 manifest와 여기서 참조하는 모든 파일을 함께 올려야 한다. 기존 manifest의 재검증과 해시 파일의 장기 캐시 정책을 그대로 적용한다. `.gz` 파일 생성만으로 HTTP gzip 전송이 보장되지는 않으며 실제 인코딩은 CDN/S3 응답 설정에 따른다.

## 줌별 경계 정밀도

- 네이버 `Polygon`은 유지한다. 앱 축척은 네이버 zoom과 반대다: 앱 `8 이상`(네이버 zoom `12 이하`)은 overview, 앱 `5 이상 8 미만`(zoom `12 초과 15 이하`)은 medium, 앱 `5 미만`(zoom `15 초과`)은 원본을 표시한다. 소수 줌도 이 구간으로 판단한다. 선택 동도 같은 등급을 적용해 인접 경계의 정밀도가 어긋나지 않게 한다.
- Webpack에서 TopoJSON 공유 arc를 전국 단위로 계산한 뒤 지역별 파일에 단순화 정점의 원본 인덱스(`lod.overview`, `lod.medium`)를 넣는다. 원본 좌표는 유지하고 별도 좌표 배열의 중복 전송을 피한다. 단순화 라이브러리는 빌드 전용 devDependency이며 브라우저 번들에 넣지 않는다.
- 유효 삼각형 면적의 근사 임계값은 overview 5,000㎡, medium 1,500㎡다. 거리나 화면 픽셀 오차의 상한을 보장하는 값이 아니다. 좌표 양자화·작은 섬이나 내부 링 필터링은 하지 않는다. 링이 세 정점 미만·면적 0·방향 반전이 되면 관련 공유 arc의 원본 정점을 보호한다.
- 실제 줌 변경이 끝난 `idle`에서 등급을 바꾼다. 같은 등급의 이동/줌에서는 좌표를 갱신하지 않으며, 등급이 바뀌면 기존 Polygon의 `setPaths`로 교체한다. 면 수가 바뀌었을 때만 해당 동의 객체를 교체한다.
- 구 파일에 LOD가 없으면 원본을 사용한다. LOD가 있지만 인덱스·면/링 개수·닫힘이 잘못되면 오류로 처리한다. 가격 탐색 법정동과 데모 SVG에는 이번 단순화를 적용하지 않는다.
