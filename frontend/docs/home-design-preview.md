# 카드형 홈 디자인 시안

`refactor/370-design` 브랜치의 `/design-preview`에서 확인한다. PostHog PR #373 변경을 포함한 기준에서 작업하며 기존 분석 코드는 수정하지 않는다.

바텀탭 없이 기능 영역을 50:50 두 열로 나눈 시안이다. 왼쪽 열에는 큰 본 방 기록 카드를, 오른쪽 열에는 위에서부터 `사용방법 알아보기`·인프라 지도·동네 찾기 카드를 쌓고, 왼쪽은 위로·오른쪽은 아래로 조금씩 어긋나게 두어 계단 모양을 만든다. 그 아래 한 줄에 정사각형 아이콘 타일 4칸을 두고 `체크리스트`·`방 비교`를 왼쪽부터 채우며 이름은 타일 아래에 표시한다(긴 이름은 두 줄까지 보이고 말줄임). 나머지 2칸은 기능이 정해질 때까지 배경 없는 빈칸으로 자리만 잡는다. 그 아래에 가로로 넘기는 최근 기록 카드가 이어진다. 마이페이지는 오른쪽 위에 배치한다. 화면 UI만 새로 구성하고 기능은 기존 앱 화면을 그대로 사용한다. 본 방 기록하기는 `/design-preview/records`, 인프라 지도는 `/map`, 동네 찾기는 `/neighborhoods`, 사용방법 알아보기는 버튼만 두고 이동할 화면은 이후 연결하며, 체크리스트는 `/checklists`, 방 비교는 `/compare`, 마이페이지는 `/me`로 이동한다. 기존 서비스 소개 페이지(`/intro`)와 소개 영상은 삭제했다.

브랜드에는 노란 배경 오리 마스코트의 머리와 목 윗부분을 잘라 만든 둥근 정사각형 이미지(`shared/assets/jachwi-sunbae-goose.webp`, 160px)만 표시한다. 로고 글자는 이후 이미지로 대체할 예정이라 넣지 않는다. 로고는 라우터 이동이 아닌 일반 링크(`/design-preview`)라서 누르면 홈을 새로 불러온다. 파비콘은 같은 이미지를 64px로 줄인 `shared/assets/favicon.png`, iOS 홈 화면 아이콘은 180px `shared/assets/apple-touch-icon.png`를 쓴다. 두 파일은 `index.html` 템플릿에서 `require`로 불러와 이미지 규칙을 거치므로 운영 빌드에서 `assets/favicon.<해시>.png`처럼 해시가 붙은 이름으로 나가고, 아이콘을 바꿔도 1년 캐시에 막히지 않는다. 기능 카드에는 집·체크보드·인프라 지도를 표현한 무채색 플랫 일러스트를 넣는다. 최근 기록의 사진 자리는 빈 영역으로 표시해 전체 크기와 간격을 검토한다.

상단 소개 제목·설명은 표시하지 않는다. 브랜드 아래에는 연한 회색 배경의 둥근 안내 영역을 두고 검은색 팁 문구를 표시한다.

데스크톱 최대 너비는 기존 서비스의 `--app-max-width`(24.375rem)를 공유한다. 휴대폰 화면에서는 홈, 지도·리스트, 매물 목록·상세 화면이 가용 너비 전체를 사용한다.

기존 `/properties`와 다른 서비스 화면은 유지한다. 본 시안은 로그인이 필요한 경로이며 기본 서비스 진입 경로는 변경하지 않는다. 랜딩 체험 작업은 별도 체크아웃에 보존한다.

`본 방 기록하기`는 `/design-preview/records`로 이동한다. 바텀탭 없이 상단에서 지도·리스트를 전환하고 지역 필터를 선택한다. 리스트와 선택 매물 카드에서는 기존 MSW 응답의 대표 사진을 미리보기로 표시하며, 사진이 없는 기록은 빈 사진 상태로 표시한다. 지도 마커를 누르면 선택한 방의 사진, 이름, 가격, 주소, 체크 진행 상태를 지도 아래 요약 카드로 보여준다. 카드에서 상세 화면으로 이동할 수 있고 닫기 버튼으로 카드를 숨긴다. 리스트 메뉴의 삭제는 기존 매물 삭제 API를 호출한다. 지도 마커 위에는 제목과 숫자 금액을 핀에 붙은 고정 크기 라벨로 표시하며, 긴 텍스트는 말줄임 처리한다. 지도는 기존 MapCanvas를 사용한다. 리스트 항목을 누르면 기존 매물 상세 페이지로 이동한다. 상세 화면은 바텀탭을 숨기고 뒤로가기 화살표 오른쪽에 매물 이름을 왼쪽 정렬로 표시하는 헤더 바로 아래에 `정보 / 체크리스트` 탭을 제공한다. 정보 탭에서는 대표 이미지와 매물 정보를 표시하고 매물 이름도 다시 크게 보여주며 매물명 옆 삭제 메뉴를 유지한다. 체크리스트 탭에는 대표 이미지를 표시하지 않고 체크 상태·메모를 이 화면에서 바로 확인하고 수정할 수 있게 한다. 상세 화면의 뒤로가기는 진입한 홈 또는 기록 지도·리스트 화면으로 돌아간다. `기록하기` 버튼은 기존 매물 등록 화면(`/properties/new`)으로 이동한다.

홈·지도·리스트는 기존 매물 목록 조회(`usePropertyList`, `GET /api/properties`)와 매물 파서를 그대로 사용한다. 별도 예시 매물·가격·좌표를 만들지 않는다. 지역은 응답 주소의 동·읍·면, 없으면 구·군·시로 구분하며 좌표 없는 기록은 리스트에서만 보여준다. 이름·금액·주소·체크 진행률도 응답 그대로 표시한다. 홈의 최근 기록은 `전체 보기` 없이 최신 5개만 옆으로 이어서 보여주고, 체크 진행 현황 없이 사진·이름·금액·주소만 표시한다. 최근 기록 카드는 동네 찾기 TOP5와 같은 공용 `HorizontalRail`로 가로로 넘기며, 레일은 본문 좌우 여백을 넘어 화면 끝까지 이어져 다음 카드가 잘려 보인다.

`/design-preview`나 `/design-preview/records`에 들어오면 같은 탭의 세션 스토리지에 시안 셸 플래그(`jachwi:design-shell`)를 저장한다. 플래그가 있으면 기존 앱 화면(지도·동네 찾기·체크리스트·방 비교·마이·매물 상세 등)도 바텀탭과 네이티브 탭바 없이 시안 셸에서 열린다. 자체 상단 내비게이션이 없는 화면에는 시안 홈으로 돌아가는 뒤로가기 화살표만 있는 상단 바를 붙이되 동네 찾기 지도(`/neighborhoods/map`)에는 붙이지 않고, 기존 홈(`/properties`)으로 돌아가던 상단 내비게이션과 매물 상세의 기본 뒤로가기는 시안 홈·기록 화면으로 돌린다. 기존 화면의 카드 표면은 테두리 없는 회색 카드로 맞춘다. 플래그는 탭을 닫으면 사라지며, 플래그가 없을 때 기존 화면 동작은 바뀌지 않는다.

로그인 화면(`/login`)도 같은 디자인으로 바꾼다. 화면 전체 높이를 쓰는 세로 배치로 로고를 위에, 닉네임·비밀번호 입력을 가운데에, `이름으로 시작하기` 버튼과 개인정보 안내를 화면 아래에 둔다. 입력은 공용 `TextField`의 큰 플로팅 라벨(`fieldSize="large"`, `floatingLabel`)을 써서 입력 전에는 placeholder를, 포커스하거나 값이 있으면 라벨을 위로 띄운다. 로그인 동작과 오류 안내, 로그인 후 이동 경로는 바꾸지 않는다.

`매물 기록하기` 카드는 노란색(`--color-brand-yellow`) 배경에 흰색 제목과 그 아래 작은 설명(`직접 본 매물을 기록해요`)을 두고, 노트·연필·집 3D 이미지(`pages/design-home/assets/record-*.webp`)를 각각 왼쪽 아래·왼쪽 위·오른쪽에 카드 가장자리에서 조금씩 잘리도록 둔다. 화면에 처음 그려질 때는 노트·연필·집 순서로 위에서 투명하게 떨어지며 나타나고, 마우스를 올리거나 키보드로 포커스하거나 손가락으로 누르면 연필은 아래로 내려가며 크게 기울고, 노트는 제자리에서 왼쪽으로 돌고, 집은 살짝 떠오르며 기운다. 움직임 줄이기 설정에서는 움직이지 않는다. 이미지 자산을 쓰기 위해 웹팩 이미지 규칙과 타입 선언에 `webp`를 추가했다. 이미지 규칙은 `asset/resource`로 두어 작은 이미지도 `data:image` URI로 번들에 넣지 않고 별도 파일 URL로 내보낸다.

인프라 지도·동네 찾기 카드, 체크리스트·방 비교 타일, 마이페이지 버튼은 같은 톤의 3D 이미지(`pages/design-home/assets/*.webp`)를 쓴다. 원본(1254px)에서 화면 표시 크기의 2배 정도로 줄여 WebP로 변환했다(카드 320px, 타일 192px, 마이페이지 96px). 카드 이미지는 오른쪽 아래 가장자리에 조금 걸치게 두고 마우스를 올리면 살짝 떠오르며 기운다.

`사용방법 알아보기` 카드는 부리보다 채도를 조금 낮춘 파란색(`#6b9ae6`) 배경에 흰색 두 줄 제목을 두고, 투명 배경 오리 이미지(`pages/design-home/assets/guide-goose.webp`, 200px)가 오른쪽 아래 가장자리에서 고개를 내밀도록 둔다. 마우스를 올리면 오리가 살짝 떠오르며 기운다.

홈의 카드와 바로가기 타일은 공통 컴포넌트로 만든다.

- `shared/ui/action-card/ActionCard`: 제목·설명과 3D 그림이 있는 기능 카드다. `tone`(`neutral`·`brand`·`informative`)으로 바탕색과 글자색을, `size`(`medium`·`large`)로 제목 크기를 정한다. 그림은 `illustration`에 넣고, 보통 `ActionCardIllustration`의 `placement`(`corner`는 오른쪽 아래 모서리에 걸침, `peek`는 아래 가장자리에서 고개를 내밂)로 놓는다. 화면 이동이면 `to`로 링크를, 동작이면 `onClick`으로 버튼을 그린다.
- `shared/ui/rail-card/RailCard`: `HorizontalRail`에 넣는 카드의 동작만 맡는 틀이다. `to`(와 라우터 `state`)를 주면 이동 링크를, `onSelect`·`selected`·`disabled`를 주면 눌림 상태가 있는 선택 버튼을 그리고 포커스·눌림·선택·비활성 표시를 맞춘다. 모양은 children과 `className`으로 정하므로 홈의 최근 기록 카드(사진 위·정보 아래)와 동네 찾기 순위 카드(`RankedCard`)가 같은 틀에 다른 내용을 넣는다.
- `shared/ui/shortcut-tile/ShortcutTile`: 정사각형 아이콘 타일과 이름으로 된 바로가기다. 타일 크기는 놓인 그리드 칸 너비를 따르고, `to`·`onClick` 규칙은 `ActionCard`와 같다.

색과 모서리는 `app/styles/tokens.css`의 토큰으로 묶어 한곳에서 바꾼다. 보조 브랜드색 `--color-brand-blue`, 카드 표면 `--color-card-surface`·`--color-card-surface-hover`, 톤별 카드 표면 `--color-card-brand-surface`·`--color-card-informative-surface`와 그 위 글자색 `--color-on-card-accent`, 화면 바탕 `--color-page-subtle`, 가격 강조 `--color-price`, 모서리 `--radius-card`·`--radius-tile`을 추가했고 글자·테두리·보조 글자·포커스는 기존 토큰을 쓴다.

두 열 계단 배치, 4칸 빠른 메뉴와 빈칸처럼 홈에만 있는 레이아웃은 재사용하기 어려워 `pages/design-home`에 둔다. 매물 기록 카드의 노트·연필·집 장면은 `ui/RecordCard`, 로고와 마이페이지 링크는 `ui/HomeHeader`, 빠른 메뉴는 `ui/QuickMenu`에서 만든다.

시안 이미지는 저장소 루트가 아닌 프론트엔드 폴더 안에서 관리한다. 화면 한 곳에서만 쓰는 이미지는 해당 페이지의 `assets/`에, 아직 화면에 붙이지 않은 홈·지도·안내 아이콘과 동네 순위(1~5위) 이미지는 `shared/assets/illustrations/`에 192px WebP로 둔다.
