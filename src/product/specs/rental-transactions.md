# 소형 주택 월세 참고 정보 기능 명세

- 상태: 팀 검토용 초안 v0.2
- 작성일: 2026-10-11
- 대상: 추천 지역의 최근 소형 주택 월세 거래 확인
- 관련 이슈: [#349 추천 지역의 소형 주택 월세 거래 정보 조회 기능을 추가한다](https://github.com/woowacourse-teams/2026-jachwi-sunbae/issues/349)

## 1. 목적과 범위

서울·경기의 지역과 가격에 익숙하지 않은 20~24세 상경 사용자가 이동 조건과 실제 계약 금액을 함께 참고하여 방을 찾아볼 동네를 좁히도록 돕는다.

사용 흐름은 **목적지 검색 → 교통 조건으로 추천된 지역 선택 → 최근 월세 거래 확인**이다. 사용자가 주택 유형·면적·보증금 조건을 별도로 선택하지 않아도 해당 지역의 소형 주택 월세 사례를 확인할 수 있도록 한다.

이 기능은 국토교통부 전월세 실거래가 자료를 활용하여 과거에 체결된 계약 사례를 제공한다. 실시간 매물 탐색, 입주 가능 여부 확인, 매물 등록·체크리스트 연결은 이번 기능 범위에 포함하지 않는다.

## 2. 요구사항

| ID           | 요구사항                                                                      |
| ------------ | ----------------------------------------------------------------------------- |
| REQ-RENT-001 | 서울 전역과 지정한 경기 15개 시·군의 소형 주택 월세 거래 정보를 제공한다.     |
| REQ-RENT-002 | 연립·다세대, 단독·다가구, 오피스텔의 5~10평 월세 사례를 제공한다.             |
| REQ-RENT-003 | 사용자가 추천 지역을 선택하면 추가 조건 입력 없이 최근 6개월 거래를 확인한다. |
| REQ-RENT-004 | 각 사례의 보증금·월세·면적·면적 기준·계약 시점을 함께 표시한다.               |
| REQ-RENT-005 | 집계한 법정동과 자료의 수집 기간·수집 시점을 안내한다.                        |
| REQ-RENT-006 | 거래 확인 중 로딩·빈 목록·조회 실패를 구분하여 안내한다.                      |

## 3. 정책

### 3.1. 표시명과 정보의 의미

- POL-RENT-001: 기능의 표시명은 **소형 주택 월세 참고 정보**다. 소형 면적만으로 원룸을 판별하지 않으며 사례를 원룸 확정 매물로 표시하지 않는다.
- POL-RENT-002: 제공하는 금액은 과거 계약 사례의 보증금과 월세다. 현재 입주 가능한 매물의 가격이나 지역의 평균 시세로 표현하지 않는다. 관리비와 관리비를 포함한 총 주거비는 제공하지 않는다.

### 3.2. 제공 지역과 주택 조건

- POL-RENT-003: 초기 제공 지역은 서울 25개 구 전체와 아래 경기 15개 시·군이다.

| 경기 제공 범위      | 시·군                        |
| ------------------- | ---------------------------- |
| 북동부              | 의정부·양주·동두천·포천·연천 |
| 동부                | 구리·남양주·가평·양평·하남   |
| 동남부 및 추가 지역 | 광주·여주·성남·용인·이천     |

- POL-RENT-004: 주택 유형은 연립·다세대, 단독·다가구, 오피스텔이다. 아파트와 월세가 0인 전세 거래는 제외한다. 주택 유형·면적·보증금 조건을 별도로 입력받지 않는다.
- POL-RENT-005: 면적은 5~10평이며 양 끝을 포함한다. 1평 = 400/121㎡ 기준으로 계산하고 표시용 반올림 평수로 포함 여부를 판단하지 않는다. 예를 들어 16.5290㎡·33.0578㎡는 포함하고, 16.5289㎡·33.0579㎡는 제외한다.
- POL-RENT-006: 연립·다세대와 오피스텔은 전용면적, 단독·다가구는 원본 자료의 계약면적을 사용한다. 각 사례에 면적 기준을 함께 표시하며 계약면적을 전용면적으로 설명하지 않는다.
- POL-RENT-007: 보증금은 0원 이상, 월세는 0원 초과인 사례를 제공한다. 보증금과 월세를 함께 표시하고 금액의 단위를 명확히 안내한다. 단위 변환으로 실제 계약 금액이 달라져서는 안 된다.

### 3.3. 집계 지역과 계약 사례

- POL-RENT-008: 집계 지역은 공식 법정동을 기준으로 한다. 시도·시군구·읍면동·리를 포함한 전체 이름을 안내하여 이름이 같은 지역을 구분할 수 있도록 한다. 행정동을 법정동과 동일하게 취급하지 않는다.
- POL-RENT-009: 신규 계약과 갱신 계약을 모두 포함한다. 계약 구분을 제공하는 경우 원본에서 확인할 수 없는 값은 미상으로 표시하며 신규로 추정하지 않는다.
- POL-RENT-010: 날짜·금액·면적이 같다는 이유만으로 서로 다른 계약 사례를 하나로 합치지 않는다. 같은 실제 계약인지 확인할 수 없는 사례를 임의로 제거하지 않는다.

### 3.4. 기간·정렬·이용 조건

- POL-RENT-011: 최근 6개월은 조회 시점의 한국 날짜에서 6개월을 뺀 날짜부터 오늘까지이며 양 끝을 포함한다. 고정 180일이 아닌 달력의 월 단위를 사용한다. 계약일을 기준으로 조회하고 미래 계약일은 제외한다.
- POL-RENT-012: 계약일이 최근인 사례부터 표시한다. 같은 계약일의 사례는 일관된 순서를 유지하며 다음 목록을 확인할 때 같은 자료 안에서 사례가 반복되거나 누락되지 않도록 한다.
- POL-RENT-013: 로그인한 사용자가 이용한다. 같은 지역을 선택한 사용자는 동일한 공공 거래 자료를 참고하며 개인이 등록한 후보 매물과 구분한다.

### 3.5. 수집 정보와 화면 상태

- POL-RENT-014: 조회 대상 기간과 실제 자료 수집 기간·수집 시점을 구분하여 안내한다. 최근 날짜의 계약이라도 수집 자료에 아직 반영되지 않았을 수 있으므로 실시간 정보로 표현하지 않는다. 수집 정보를 확인할 수 없는 경우 날짜를 임의로 표시하지 않는다.
- POL-RENT-015: 조회한 지역에 제공할 사례가 없으면 ‘최근 6개월 내 수집된 거래 정보가 없습니다’라고 안내한다. 이를 해당 지역에 월세 주택이나 실제 거래가 없다는 의미로 표현하지 않는다. 확인할 수 없는 법정동 이름을 추측하여 표시하지 않는다.
- POL-RENT-016: 조회 실패와 정상적인 빈 목록을 구분한다. 자료를 불러오는 중에는 로딩 상태를 표시하고, 조회 실패 시 실패 안내와 재시도 수단을 제공한다. 선택한 지역이 바뀌면 이전 지역의 결과를 새 지역의 정보로 표시하지 않는다.

## 5. 미정 사항

- 추천 지역이 여러 법정동에 걸쳐 있는 경우의 집계 범위와 안내 방식.
- 자료 갱신 주기와 수집 정보가 오래된 경우의 안내 기준.
- 취소·정정된 거래의 반영 기준과 동일 실제 계약을 식별할 수 있는 경우의 중복 처리 기준.
