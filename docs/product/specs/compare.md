# 매물 비교·PDF 기능 명세

## 1. 목적과 범위

사용자는 여러 후보의 저장된 정보를 한 문서에서 비교한다. 자신의 매물 선택·선택 순서·PDF 생성·다운로드·기록 일치를 다룬다.

## 2. 요구사항

- `REQ-COMPARE-001`: 자신의 후보 매물을 선택해 기록 PDF를 내려받는다. 선택 개수는 1~5개다. 한 개만 고르면 그 매물의 기록만 담는다.
- `REQ-COMPARE-002`: 선택한 순서를 PDF에서도 유지한다.
- `REQ-COMPARE-003`: 첫 부분에서 기본 정보와 현장 체크 집계를 나란히 보여준다.
- `REQ-COMPARE-004`: 매물별 상세에 기본·부가 정보, 모든 조회 가능한 사진, 자유 메모, 현재 적용된 현장 체크리스트의 모든 질문·상태·항목 메모를 포함한다.
- `REQ-COMPARE-005`: 다른 회원·삭제된 매물과 삭제·제외된 기록은 새 PDF에 포함하지 않는다.

## 3. 정책

### 3.1. 선택과 생성

- `POL-COMPARE-001`: 서로 다른 자기 매물 1~5개를 선택한다.
- `POL-COMPARE-002`: 선택 순서를 요약의 매물 순서와 매물별 상세 순서에 동일하게 적용한다.
- `POL-COMPARE-003`: 양식 교체로 현재 기록에서 빠진 항목과 논리 삭제된 사진은 제외한다. 삭제한 사용자 양식에서 과거에 복사한 매물 기록은 유지하여 포함한다.

- `POL-COMPARE-004`: 계약 전 체크리스트는 적용 여부와 관계없이 요약·매물별 상세·질문·평가·메모에서 제외한다. 과거 기록은 삭제하지 않고 PDF 출력에서만 제외한다.
- `POL-COMPARE-005`: 요약과 상세의 진행 막대는 전체 현장 항목 수를 기준으로 괜찮음은 파랑, 주의는 빨강, 미확인은 회색으로 표시한다. 항목이 없으면 회색 빈 막대와 `0/0 확인`을 표시한다.

### 3.2. 포함할 기록과 원본 명세

| 구역                  | 포함할 내용                                                                 |
| --------------------- | --------------------------------------------------------------------------- |
| 처음의 비교 요약      | 선택 순서별 이름·주소·보증금·월세 등 기본 정보, 현장 체크 집계              |
| 매물별 기본·부가 정보 | 저장한 이름·위치·금액·입주 가능일·방 옵션·관리비·공과금·방문 일정·확인한 곳 |
| 사진                  | 논리 삭제되지 않고 정상 등록된 모든 사진.                                   |
| 자유 메모             | 마지막 저장 완료된 매물 자유 메모. 미작성하거나 비운 경우 빈 문자열         |
| 체크 기록             | 현재 적용한 현장 양식 이름·모든 질문·순서·상태·항목 메모와 집계             |

## 4. 인수 기준

| ID             | 조건과 행동                                                                 | 관찰할 결과                                                                 |
| -------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| AC-COMPARE-001 | 더미 매물 1개와 5개를 각각 선택해 PDF를 생성한다.                           | PDF를 내려받아 열 수 있고 선택한 매물이 포함된다.                           |
| AC-COMPARE-002 | 0개나 6개 또는 같은 매물 ID 중복으로 생성을 시도한다.                       | 허용하지 않는 선택임을 안내하고 잘못된 PDF를 생성하지 않는다.               |
| AC-COMPARE-003 | B→A 순서로 선택해 생성한다.                                                 | 요약과 상세 모두 B→A 순서다.                                                |
| AC-COMPARE-004 | 서로 다른 금액·부가 정보·메모·현장 체크 결과가 있는 더미 매물을 선택한다.   | PDF의 값이 각 매물 재조회 결과와 일치하고 다른 매물의 기록이 섞이지 않는다. |
| AC-COMPARE-005 | 사진을 논리 삭제하거나 양식을 교체한 뒤 새 PDF를 생성한다.                  | 삭제 사진·교체로 제외된 항목은 없고 현재 결과가 포함된다.                   |
| AC-COMPARE-006 | 원본 사용자 양식을 논리 삭제한 뒤 기존 매물의 PDF를 생성한다.               | 매물에 이미 복사된 질문과 기록은 유지된다.                                  |
| AC-COMPARE-007 | 과거에 적용된 계약 전 체크리스트가 있는 매물과 미적용 매물을 함께 선택한다. | 두 경우 모두 PDF 전체에서 계약 전 제목·질문·평가·메모가 출력되지 않는다.    |
| AC-COMPARE-008 | 괜찮음 3개·주의 1개·미확인 1개가 있는 PDF를 생성한다.                       | 요약·상세의 진행 막대가 파랑 60%·빨강 20%·회색 20%로 표시된다.              |

## 5. 미정 사항과 결정 근거

현재 미정 사항은 없다.
