# 매물 기능 명세

- 상태: 검토용 초안 v0.1 / 작성일: 2026-09-13 / 대상: MVP1-2

## 1. 목적과 범위

사용자는 후보 매물의 기본·부가 정보를 등록하고 다시 조회·수정·삭제한다.

매물은 사진·자유 메모·체크 기록을 묶는 기준이다.

## 2. 요구사항

- `REQ-PROP-001`: 자신의 매물을 등록·조회·수정·삭제한다.
- `REQ-PROP-002`: 보증금,월세 및 이름은 필수로 입력한다. 이름은 trim 후 1자 이상 30자 이하이다. 등록 화면은 이름의 초기값으로 `새 매물`을 제공한다.
- `REQ-PROP-003`: 지도에서 위치를 고르거나 주소 검색 결과를 선택한다. 주소 미입력·위치 조회 실패에는 지도 명세의 기본값을 사용한다.
- `REQ-PROP-004`: 목록에서 이름·주소·금액·대표 사진과 체크리스트 진행 현황을 확인한다.
- `REQ-PROP-005`: 목록을 정해진 순서로 조회한다.
- `REQ-PROP-006`: 상세에서 기본·부가 정보, 사진·메모와 체크 진행 현황을 확인한다.
- `REQ-PROP-007`: 삭제 전에 삭제한 매물은 되돌릴 수 없다는 안내를 하고 사용자가 취소할 수 있게 한다.
- `REQ-PROP-008`: 입주 가능일, 방 옵션, 관리비·포함 공과금, 방문 일정, 확인한 곳을 입력·수정한다.
- `REQ-PROP-009`: 등록 성공 후 생성한 매물 상세로 이동하고 재진입해도 저장 정보를 확인한다.
- `REQ-PROP-010`: 등록 시 현장·계약 전 체크리스트를 자동 적용한다. 양식 선택 규칙은 체크리스트 명세를 따른다.
- `REQ-PROP-011`: 매물 전체에 대한 하나의 자유 메모를 조회·수정한다.

## 3. 정책

### 3.1. 기본 정보

- `POL-PROP-001`: 프론트엔드는 등록 시작 시 이름 값으로 `새 매물`을 채우고, 사용자가 이름 입력란을 선택하면 직접 입력하도록 기존 값을 비운다. 서버는 trim 후 1자 이상 30자 이하의 이름만 허용한다.
- `POL-PROP-002`: 보증금·월세는 필수이며 0을 허용하고 만원 단위로 입력한다. 미입력과 0을 구분한다.
- `POL-PROP-003`: 확인한 곳은 URL·앱·중개사 등 발견 경로를 기록하는 선택 항목이다. 최대 500자.
- `POL-PROP-004`: 주소는 지도 선택 또는 검색 결과 선택으로입력한다.
- `POL-PROP-005`: 주소와 좌표는 같은 선택 결과를 가리킨다. 좌표는 위도·경도를 한 쌍으로 다룬다.
- `POL-PROP-006`: 수정에도 등록과 같은 필수값·기본값·주소 확정 규칙을 적용한다.

### 3.2. 부가 정보

- `POL-PROP-007`: 관리비는 수도세·전기세·가스비·인터넷 중 여러 개를 선택한다. 입력 단위는 만원이다.
- `POL-PROP-008`: 방 옵션은 에어컨·냉장고·세탁기·싱크대·가스레인지·전자레인지·신발장·옷장·침대·책상·TV·인덕션 중 여러 개를 선택한다.

### 3.3. 개수·정렬·저장

- `POL-PROP-009`: 최대 30개 조회 가능하다. 논리 삭제된 매물은 개수에서 제외한다.
- `POL-PROP-010`: 목록은 생성 시각 내림차순, 같으면 매물 ID 내림차순한다.

### 3.4. 자유 메모

- `POL-PROP-011`: 자유 메모는 매물에 포함된 단일 값이며 별도의 생성·삭제 생명주기를 갖지 않는다. 매물을 등록하면 빈 문자열로 시작한다.
- `POL-PROP-012`: 자유 메모는 기본·부가 정보 수정과 분리된 저장 동작으로 전체 교체한다. 기본·부가 정보를 수정해도 기존 자유 메모는 유지한다.
- `POL-PROP-013`: 자유 메모는 null을 허용하지 않고 최대 2,000자까지 저장한다. 빈 문자열은 메모를 비우는 값으로 허용한다.
- `POL-PROP-014`: 작성한 자유 메모가 없으면 조회 결과로 빈 문자열을 제공한다.
