# 회원·인증 기능 명세

- 상태: 검토용 초안 v0.1 / 작성일: 2026-09-13 / 대상: MVP1-2

## 1. 목적과 범위

사용자는 닉네임으로 서비스를 시작하고 같은 회원의 기록을 이어 사용한다.

선택 비밀번호로 접근을 보호하며, 로그인 유지·로그아웃과 다른 회원의 기록 접근 제한을 제공한다.

회원과 실제 사람은 일대일 관계가 아니다. 비밀번호 없는 같은 닉네임을 입력하면 같은 회원 기록을 공유한다. 소유권 검증은 서로 다른 회원을 기준으로 한다.

## 2. 요구사항

- `REQ-AUTH-001`: 외부 계정 연결 없이 닉네임과 선택 비밀번호로 시작한다.
- `REQ-AUTH-002`: 처음 사용하는 닉네임이면 회원을 만들고, 같은 닉네임으로 다시 시작하면 그 회원의 기록을 제공한다.
- `REQ-AUTH-003`: 비밀번호 없는 닉네임은 같은 닉네임을 입력한 사람이 기록을 공유한다. 시작 화면에서 이 접근 방식을 안내한다.
- `REQ-AUTH-004`: 비밀번호를 설정한 닉네임은 올바른 비밀번호가 있어야 접근한다.
- `REQ-AUTH-005`: 로그인 후 매물 목록으로 이동한다. 마이페이지에서 닉네임과 비밀번호 보호 여부를 보여준다.
- `REQ-AUTH-006`: 로그아웃하면 개인 데이터 접근을 종료하고 로그인 화면으로 이동한다. 이전 회원의 화면 데이터가 다음 회원에게 남지 않는다.
- `REQ-AUTH-007`: 다른 회원의 자원에 접근하지 못하게 한다. 공개 API를 제외한 미인증 API는 401, 다른 회원의 자원은 404로 응답한다.
- `REQ-AUTH-008`: 로그인 실패 시 실패를 알리고 다시 입력할 수 있게 한다. 실패를 신규 회원 생성이나 로그인 성공으로 처리하지 않는다.

## 3. 정책

### 3.1. 계정 식별과 보호

- `POL-AUTH-001`: 닉네임은 필수이며 1~30자로 입력한다.
- `POL-AUTH-002`: 비밀번호는 선택이며, 입력하는 경우 4~30자로 입력한다. 생략하거나 빈 값이면 비밀번호 없이 시작하고, 공백도 비밀번호 글자로 센다.
- `POL-AUTH-003`: 로그인한 회원은 다른 회원의 데이터를 조회,변경,삭제할 수 없다. 비밀번호 없는 같은 닉네임으로 시작한 사람들은 같은 회원의 기록을 이용한다.
- `POL-AUTH-004`: 닉네임은 앞뒤 공백을 제거한 값으로 구분한다. 대소문자와 그 외 문자는 입력한 그대로 비교한다.
- `POL-AUTH-005`: 같은 닉네임에 비밀번호 없는 회원과 비밀번호로 보호된 회원이 각각 하나씩 존재할 수 있다. 두 회원은 기록을 공유하지 않는다.
  - 비밀번호 없이 시작하면 그 닉네임의 비밀번호 없는 회원으로 시작하고, 없으면 만든다.
  - 비밀번호를 입력해 시작하면 그 닉네임의 보호된 회원으로 시작한다. 보호된 회원이 없으면 입력한 비밀번호로 만들고, 있으면 비밀번호가 일치해야 한다.
- `POL-AUTH-006`: 인증·게스트·시스템 체크 항목 조회와 지도 조회처럼 명세에서 공개로 정한 API는 Access Token 없이 사용할 수 있다. 그 외 `/api` 요청에는 인증이 필요하다.
- `POL-AUTH-008`: 게스트 매물 목록과 사용자 체크리스트 목록은 인증 없이 조회할 수 있다.
- `POL-AUTH-009`: 게스트 API는 조회만 제공한다. 생성·수정·삭제 요청은 게스트 기능으로 허용하지 않는다.

## 4. 인수 기준

| ID          | 조건과 행동                                                                                                            | 관찰할 결과                                                                                    |
| ----------- | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| AC-AUTH-001 | 준비한 새 닉네임으로 비밀번호 없이 시작한다.                                                                           | 서비스를 시작하고 해당 회원으로 매물을 등록·재조회할 수 있다.                                  |
| AC-AUTH-002 | 더미 계정 A에서 기록을 저장하고 로그아웃한 뒤 같은 닉네임으로 시작한다.                                                | A의 기록이 그대로 조회되고 별도 회원으로 분리되지 않는다.                                      |
| AC-AUTH-003 | 비밀번호 없는 더미 닉네임에 다른 브라우저에서 접근한다.                                                                | 같은 회원의 기록을 이용할 수 있다.                                                             |
| AC-AUTH-004 | 보호된 더미 닉네임에 올바른 비밀번호와 잘못된 비밀번호로 각각 시도한다.                                                | 올바른 경우에만 개인 기록에 접근한다.                                                          |
| AC-AUTH-005 | 서로 다른 회원 A·B를 준비하고 B의 자원 ID로 조회·변경을 시도한다.                                                      | B의 내용이 노출되거나 변경되지 않는다. 미인증 401·타인 자원 404도 확인한다.                    |
| AC-AUTH-006 | 신규 닉네임을 1자·30자로 각각 입력하고, 별도로 빈 값·31자로 시작을 시도한다.                                           | 1자·30자는 허용한다. 빈 값·31자는 허용하지 않으며 해당 요청으로 회원이 생성되지 않는다.        |
| AC-AUTH-07  | 서로 다른 신규 닉네임에 비밀번호를 생략하거나 4자, 30자로 입력한다. 별도로 1~3자,31자로 시작을 시도한다.               | 생략, 4자, 30자는 허용한다. 1~3자,31자는 허용하지 않으며 해당 요청으로 회원이 생성되지 않는다. |
| AC-AUTH-008 | 비밀번호 없는 닉네임 A가 있을 때 A와 비밀번호로 시작하고, 반대로 보호된 닉네임 B가 있을 때 B를 비밀번호 없이 시작한다. | 각각 별도 회원으로 시작되며 서로의 기록이 보이지 않는다.                                       |
| AC-AUTH-009 | 보호된 닉네임에 다른 비밀번호로 시작을 시도한다.                                                                       | 로그인에 실패하고 새 회원이 생성되지 않는다.                                                   |
| AC-AUTH-010 | 대소문자만 다른 두 닉네임(`Lee`, `lee`)으로 각각 시작한다.                                                             | 서로 다른 회원으로 시작된다.                                                                   |
| AC-AUTH-011 | 로그인하지 않고 게스트 매물 목록을 조회한다.                                                                           | 고정된 샘플 매물 목록을 정상적으로 확인한다.                                                   |
| AC-AUTH-012 | 로그인하지 않고 게스트 사용자 체크리스트 목록을 조회한다.                                                              | 고정된 샘플 사용자 체크리스트 목록을 정상적으로 확인한다.                                      |
| AC-AUTH-013 | 로그인하지 않고 주소 검색·역지오코딩·주변 시설 조회를 실행한다.                                                        | 인증 오류 없이 지도 조회 결과를 확인한다.                                                      |
