# 날씨 기능 명세

- 상태: 검토용 초안 v0.1 / 작성일: 2026-10-26 / 대상: MVP1-2

## 1. 목적과 범위

사용자는 현재 위치의 날씨를 확인하고, 아침·저녁에 생활에 필요한 날씨 안내를 푸시로 받는다.

기상청 전국 예보 수집, 현재 위치 날씨 조회, 위치·기기 등록, 정기 생활 날씨 알림을 다룬다. 모바일의 GPS·권한 처리와 FCM 토큰 획득, 날씨 화면은 범위에 포함하지 않는다.

## 2. 요구사항

- `REQ-WEATHER-001`: 서버는 기상청 단기예보를 발표마다 전국 격자 단위로 미리 수집해 저장한다.
- `REQ-WEATHER-002`: 위도·경도와 날짜로 그 지역의 00–23시 시간별 예보와 일 최저·최고기온을 조회한다.
- `REQ-WEATHER-003`: 회원은 알림에 사용할 위치를 저장·조회·삭제한다.
- `REQ-WEATHER-004`: 회원은 알림 수신 동의를 켜고 끄며, 알림을 받을 기기 하나를 등록·해제한다.
- `REQ-WEATHER-005`: 수신에 동의한 회원에게 매일 07시에 오늘, 22시에 내일의 생활 날씨 알림을 보낸다.
- `REQ-WEATHER-006`: 회원은 받은 알림의 당시 내용을 상세 조회한다.

## 3. 정책

### 3.1. 수집

- `POL-WEATHER-001`: 기상청 발표 시각(KST 02·05·08·11·14·17·20·23시) 15분 뒤에 가장 최근 발표분을 수집한다. 놓친 발표분은 보충하거나 재시도하지 않는다.
- `POL-WEATHER-002`: 발표 후 1–48시간의 시간별 8개 요소와 날짜별 TMN·TMX를 수집한다. 당일 TMN은 02시 발표까지, 당일 TMX는 11시 발표까지만 요청한다.
- `POL-WEATHER-003`: `-99`·`-999`는 결측으로 저장하지 않는다. 0과 음수 기온은 정상 값이다.
- `POL-WEATHER-004`: 수집이 완료된 발표분만 조회·알림에 사용한다. 이전 발표분은 최신 발표분의 값을 덮어쓰지 않는다.
- `POL-WEATHER-005`: 매일 00:30에 오늘 이전의 예보를 삭제한다.

| 요소 | 의미·단위                                       |
| ---- | ----------------------------------------------- |
| TMP  | 1시간 기온, ℃                                   |
| SKY  | 하늘상태: 1 맑음, 3 구름많음, 4 흐림            |
| PTY  | 강수형태: 0 없음, 1 비, 2 비/눈, 3 눈, 4 소나기 |
| POP  | 강수확률, %                                     |
| PCP  | 1시간 강수량, mm                                |
| SNO  | 1시간 신적설, cm                                |
| REH  | 상대습도, %                                     |
| WSD  | 풍속, m/s                                       |
| TMN  | 일 최저기온, ℃                                  |
| TMX  | 일 최고기온, ℃                                  |

### 3.2. 조회와 위치

- `POL-WEATHER-006`: 위경도는 기상청 격자로 변환한다. 격자 범위 밖이거나 잘못된 좌표는 거부한다.
- `POL-WEATHER-007`: 조회 날짜를 제한하지 않는다. 생략하면 KST 오늘이며, 값이 없는 시각과 요소는 `null`로 응답한다.
- `POL-WEATHER-008`: 위치는 정확한 위경도가 아닌 격자만 회원당 하나 저장한다. 새 위치는 기존 위치를 덮어쓴다.

### 3.3. 알림

- `POL-WEATHER-009`: 알림 수신 동의는 기본 OFF다. 동의, 등록된 기기, 저장된 위치가 모두 있어야 발송한다.
- `POL-WEATHER-010`: 07시는 오늘 07–23시, 22시는 내일 00–23시를 분석한다. 대상 시각의 TMP·PTY가 하나라도 없으면 그 회원에게 발송하지 않는다.
- `POL-WEATHER-011`: 회원 × 날짜 × 슬롯마다 최대 한 번 발송한다. 실패해도 재시도하지 않는다.
- `POL-WEATHER-012`: 알림 위치는 실시간 GPS가 아닌 마지막 저장 격자다. 앱이 위치를 다시 저장하지 않으면 이전 지역 기준으로 발송된다.
- `POL-WEATHER-013`: 아래 조건을 만족한 생활 안내만 만들며, 공식 기상특보가 아니다.

| 순서 | 안내      | 조건                                                | 본문(07시는 "오늘", 22시는 "내일")                           |
| ---- | --------- | --------------------------------------------------- | ------------------------------------------------------------ |
| 1    | 눈        | PTY 2(비/눈) 또는 3(눈)이 한 시각이라도 있음        | 오늘 눈이 예상돼요. 이동할 때 주의하세요!                    |
| 2    | 비        | PTY 1(비), 2(비/눈), 4(소나기)가 한 시각이라도 있음 | 오늘 비 예보가 있어요. 우산을 챙기세요!                      |
| 3    | 추위·동파 | 시간별 기온 또는 일 최저기온이 -5℃ 이하             | 오늘 영하 5℃ 이하 추위가 예상돼요. 수도관 보온을 점검하세요! |
| 4    | 일교차    | 일 최고 − 최저기온이 10℃ 이상                       | 오늘 일교차가 10℃ 이상이에요. 겉옷을 챙기세요!               |
| 5    | 빨래 추천 | 09–18시 모든 시각 PTY=0이고 평균 습도 60% 이하      | 오늘은 비 예보가 없고 습도가 낮아요. 빨래하기 괜찮겠어요!    |

- `POL-WEATHER-014`: 제목은 항상 "자취선배 생활정보"다. 본문은 순서가 가장 앞선 안내 하나이며, 안내가 없으면 대상 시간대의 최저·최고 기온(예: "오늘 07~~23시 예보기온 5~~20℃")이다.
- `POL-WEATHER-015`: 발송한 알림의 제목·본문·안내 목록을 저장하고, 이후 예보가 바뀌어도 당시 내용을 유지한다.
- `POL-WEATHER-016`: Prod를 제외한 환경에서는 회원이 자기 기기로 고정 문구의 테스트 알림을 즉시 보낼 수 있다. 수신 동의·위치·예보와 무관하며 이력을 저장하지 않는다.

| ID             | 조건과 행동                                           | 관찰할 결과                                              |

| AC-WEATHER-001 | 05:15에 수집을 실행한다.                              | 05시 발표분의 48시간 예보가 저장되고 완료로 기록된다.    |
| AC-WEATHER-002 | 수집 도중 실패한 발표분이 있는 상태에서 조회한다.     | 실패한 발표분의 값은 응답에 나오지 않는다.               |
| AC-WEATHER-003 | 서울 좌표로 오늘 날씨를 조회한다.                     | 격자 (60, 127)의 00–23시 24개 시간과 TMN·TMX를 반환한다. |
| AC-WEATHER-004 | 수집 범위 밖의 날짜를 조회한다.                       | 24개 시간의 값이 모두 `null`이다.                        |
| AC-WEATHER-005 | 위치를 저장한 뒤 다른 좌표로 다시 저장한다.           | 위치는 하나이며 새 격자로 바뀐다.                        |
| AC-WEATHER-006 | 동의·기기·위치를 갖춘 회원에게 07시 알림을 실행한다.  | 알림 하나가 저장되고 발송된다.                           |
| AC-WEATHER-007 | 같은 슬롯의 알림을 두 번 실행한다.                    | 두 번째 실행은 발송하지 않는다.                          |
| AC-WEATHER-008 | 동의를 끄거나 위치를 삭제한 회원에게 알림을 실행한다. | 발송하지 않는다.                                         |
| AC-WEATHER-009 | 대상 시각에 PTY 2가 있고 최저기온이 -6℃다.            | 본문은 눈 문구이며 안내 목록에 비·추위도 포함된다.       |
| AC-WEATHER-010 | 주의 조건이 하나도 없는 날을 분석한다.                | 기온 범위를 본문으로 하고 안내 목록은 비어 있다.         |
| AC-WEATHER-011 | 다른 회원의 알림 상세를 조회한다.                     | 내용이 노출되지 않는다.                                  |

## 5. 미정 사항

- 기상청 발표 후 실제 공개 지연(현재 15분 가정)은 실측하지 않았다.
- 실기기 FCM 수신과 Dev·Prod 알림 활성화는 Firebase·앱 연동 후 진행한다.
