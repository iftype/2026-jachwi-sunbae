# 사진 기능 명세

- 상태: 검토용 초안 v0.1 / 작성일: 2026-09-13 / 대상: MVP1-2

## 1. 목적과 범위

사용자는 매물에 실제 사진을 남기고 대표 사진으로 구분한다.

사진의 업로드·조회·대표 지정·논리 삭제와 실패 안내를 다룬다.

## 2. 요구사항

- `REQ-PHOTO-001`: 자신의 매물에 사진을 업로드·조회·삭제한다.
- `REQ-PHOTO-002`: 첫 업로드 사진을 자동 대표로 지정하며, 대표 사진을 직접 지정할 수 있다.
- `REQ-PHOTO-003`: 매물 목록·상세에서 대표 사진을 보여주고 사진이 없으면 기본 이미지를 보여준다.
- `REQ-PHOTO-004`: 업로드 결과를 사진별로 확인하고 실패한 사진을 다시 시도할 수 있다.
- `REQ-PHOTO-005`: 사진을 저장한 뒤 재진입하여 조회할 수 있다.
- `REQ-PHOTO-006`: 대표 사진 삭제 시 남은 첫 사진을 대표로 지정한다.

## 3. 정책

### 3.1. 허용 파일과 한도

- `POL-PHOTO-001`: 한 장당 최대 5MiB, 매물당 최대 30장이다. 한도 초과 시 등록을 거부한다.
- `POL-PHOTO-002`: JPG·JPEG·PNG·WebP·HEIC·HEIF를 허용한다. 허용 목록 밖의 형식은 거부한다.

### 3.2. 표시와 대표 사진

- `POL-PHOTO-003`: 업로드에 성공한 순서대로 표시한다.
- `POL-PHOTO-004`: 첫 사진을 대표로 자동 지정한다. 대표 사진을 삭제하면 남은 사진의 표시 순서상 첫 사진을 대표로 지정한다. 남은 사진이 없으면 기본 이미지를 표시한다.

### 3.3. 저장·권한·삭제

- `POL-PHOTO-005`: 본인 매물의 사진 메타데이터와 콘텐츠만 조회·변경한다. 삭제된 부모 매물의 사진에도 접근하지 못한다.
- `POL-PHOTO-006`: 파일 저장과 사진 정보 저장이 모두 성공한 뒤 등록 완료로 처리한다. 하나라도 실패하면 정상 사진으로 노출하지 않는다.
- `POL-PHOTO-007`: 사진 개별 삭제는 논리 삭제로 처리한다. DB 데이터와 실제 파일은 유지하고 조회·대표 지정·새 PDF에서 제외한다.
- `POL-PHOTO-008`: 여러 파일 업로드 중 일부만 실패하면 성공분과 실패분을 구분한다. 실패분의 재시도가 성공분을 중복 등록하지 않게 한다.

## 4. 인수 기준

| ID           | 조건과 행동                                                     | 관찰할 결과                                                                       |
| ------------ | --------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| AC-PHOTO-001 | JPEG·PNG·WebP·HEIC·HEIF 정상 파일을 각각 업로드한다.            | 등록 후 재조회할 수 있다.                                                         |
| AC-PHOTO-002 | 정상 이미지의 용량을 정확히 5MiB와 그 초과로 준비해 업로드한다. | 경계값은 크기 제한으로 거부되지 않고 초과 파일은 등록되지 않는다.                 |
| AC-PHOTO-003 | 29장인 매물에 30번째, 이어 31번째 사진을 업로드한다.            | 30번째는 허용하고 31번째는 거부한다.                                              |
| AC-PHOTO-004 | 완료 순서가 A·B·C인 사진을 다시 조회한다.                       | A·B·C 순서가 유지된다.                                                            |
| AC-PHOTO-005 | 대표 A를 B로 변경하고 재조회한다.                               | 대표는 B 하나이며 목록·상세에서 B를 보여준다.                                     |
| AC-PHOTO-006 | A·B·C 중 대표 A를 삭제한다.                                     | A는 조회·새 PDF에서 제외되고 B가 대표가 된다. A의 DB 정보와 실제 파일은 남는다.   |
| AC-PHOTO-007 | 마지막 사진 한장을 삭제한다.                                    | 사진 목록은 비고 대표 영역은 기본 이미지를 표시한다. 파일은 물리 삭제되지 않는다. |
| AC-PHOTO-008 | 다른 회원의 사진과 삭제된 매물의 사진에 직접 접근한다.          | 내용이 노출되지 않고 변경할 수 없다.                                              |
| AC-PHOTO-009 | 파일 저장 또는 사진 정보 저장 중 하나를 실패시킨다.             | 등록 성공으로 표시하거나 정상 갤러리·PDF에 포함하지 않는다.                       |
| AC-PHOTO-010 | 여러 업로드 중 일부를 실패시킨 후 실패분만 재시도한다.          | 성공분은 유지되고 중복되지 않으며 실패분의 결과를 구분할 수 있다.                 |
| AC-PHOTO-011 | 30장 중 한 장을 논리 삭제한 후 새 사진을 추가한다.              | 조회 가능한 사진 수 기준으로 다시 30장까지 등록할 수 있다.                        |
