# 자취선배 제품 개요

- 상태: 초안 v0.3 - ‘노션의 통합 1차 MVP_UX개선’ 페이지를 통해 모카가 정리한 초안
- 작성일: 2026-09-13
- 수정일: 2026-09-28
- 대상 제품 버전: 미정(팀원들과 관리 및 표기 논의)

이 문서는 자취선배의 목적, 기능 범위, 용어와 핵심 사용자 흐름을 설명한다.

## 1. 제품 목적

자취선배는 집을 구하는 사용자가 후보 매물의 정보와 확인한 내용을 매물별로 기록하고, 여러 후보의 기록을 비교해 선택할 수 있도록 돕는 서비스다.

사용자는 매물의 금액, 위치, 부가 정보, 사진, 메모와 체크 결과를 한곳에 모은다. 집을 확인하는 과정에서 남긴 기록을 다시 조회하고, 후보들의 저장된 정보를 비교 PDF로 확인한다.

### 해결하려는 문제

- 여러 매물의 금액, 위치, 사진과 메모를 각각 관리하면 어떤 정보가 어느 매물의 것인지 구분하기 어렵다.
- 현장과 계약 전 확인할 항목을 기억에 의존하면 질문을 빠뜨리거나, 확인한 내용과 아직 확인하지 않은 내용을 혼동할 수 있다.
- 여러 집을 확인한 뒤 기억만으로 비교하면 각 매물에서 발견한 차이를 놓칠 수 있다.

### 사용자가 얻는 결과

- 후보 매물별로 기본 정보와 확인 기록을 모아 다시 볼 수 있다.
- 체크 항목을 통해 확인한 내용과 아직 확인하지 않은 내용을 구분할 수 있다.
- 매물 위치와 주변 시설 정보를 함께 살펴볼 수 있다.
- 후보 매물의 저장된 기록을 나란히 확인하고 직접 선택을 판단할 수 있다.

## 2. 대상 사용자와 사용 맥락

주요 대상은 거주할 집을 구하면서 후보 매물의 조건을 기록하고 비교하려는 사용자다.

현장에서 기록을 남기고 이동 후 다시 확인하는 사용을 고려한다.

| 사용 맥락               | 사용자의 목적                                  | 관련 기능                            |
| ----------------------- | ---------------------------------------------- | ------------------------------------ |
| 후보를 발견했을 때      | 나중에 다시 확인할 수 있도록 정보를 모은다     | 매물 등록, 주소·위치 선택, 자유 메모 |
| 현장에서 집을 확인할 때 | 확인할 질문을 보고 실제 관찰 내용을 기록한다   | 현장 체크리스트, 사진, 항목 메모     |
| 계약 전 확인할 때       | 계약 전 단계의 질문을 확인하고 결과를 기록한다 | 계약 전 체크리스트, 항목 메모        |
| 여러 후보를 검토할 때   | 각 매물의 조건과 기록을 비교한다               | 목록·상세, 주변 분석, 비교 PDF       |

## 3. 기능 범위

| 기능 영역           | 제공하려는 동작                                                                                                                                                                                     |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 회원·인증           | 외부 계정 연결 없이 닉네임으로 시작한다.<br>처음 사용하는 닉네임으로 기록 공간을 만들고, 기존 닉네임으로 이전 기록을 이어 사용한다.<br>선택 비밀번호, 로그인 유지, 로그아웃과 접근 권한을 제공한다. |
| 게스트 체험 | 로그인 없이 고정된 샘플 매물·사용자 체크리스트와 지도 조회 기능을 체험한다.<br>실제 회원 데이터와 DB 데이터는 조회하거나 변경하지 않는다. |
| 매물                | 후보 매물을 등록·조회·수정·삭제한다. 기본 정보와 부가 정보를 기록하고 목록과 상세에서 확인한다.                                                                                                     |
| 사진                | 매물에 사진을 업로드하고 조회·삭제한다. 대표 사진을 지정하고 업로드 결과를 확인한다.                                                                                                                |
| 매물 메모           | 매물에 대한 하나의 자유 메모를 작성·수정하고 저장된 내용을 다시 확인한다.                                                                                                                           |
| 체크리스트          | 시스템 제공 항목으로 사용자 양식을 구성한다.<br>기본 또는 사용자 체크리스트를 매물에 적용·교체하고, 상태·항목 메모·진행 현황을 관리한다.                                                            |
| 지도·주소·주변 분석 | 주소를 검색하거나 지도에서 위치를 선택해 매물에 연결한다.<br>매물 위치와 주변 시설을 확인하고 위치 조회·외부 서비스 실패에 대응한다.                                                                |
| 매물 비교·PDF       | 자신의 후보 매물을 선택해 기본·부가 정보, 사진, 자유 메모와 체크 기록을 담은 비교 PDF를 내려받는다.                                                                                                 |

> **각 기능의 상세 동작과 검증 기준은 연결된 기능 명세에서 관리한다. 각 명세는 다음 목차로 구성한다.**
>
> 1. 목적과 범위: 해당 기능이 해결하는 사용자 목적과 제공 범위.
> 2. 요구사항: 사용자가 할 수 있어야 하는 일.
> 3. 정책: 입력값, 제한, 기본값, 상태 변화, 권한과 예외 처리 규칙.
> 4. 인수 기준: 요구사항을 충족했다고 인정할 수 있는 관찰 가능한 결과.
> 5. 미정 사항과 결정 근거: 세부 멍세 작성 중 추가로 발견된 논의사항과 결정 내용 기록.

## 4. 공통 용어

| 용어                   | 의미                                                                                                                                                                                                                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 사용자                 | 자취선배를 이용하는 사람.                                                                                                                                                                                                                                                        |
| 게스트 | 로그인하지 않고 실제 회원 데이터와 분리된 고정 샘플 데이터로 서비스를 체험하는 사용자. |
| 회원                   | 닉네임과 비밀번호 설정 여부로 식별되어 매물과 기록을 소유하는 서비스 내 계정. 같은 닉네임에 비밀번호 없는 회원과 보호된 회원이 따로 있을 수 있다.<br>비밀번호 없는 같은 닉네임은 여러 사람이 같은 회원 기록을 사용할 수 있으므로, 사람과 회원이 항상 일대일로 대응하지는 않는다. |
| 후보 매물              | 사용자가 거주 후보로 등록하고 비교하는 집. 이 문서에서는 줄여서 매물이라고 부른다.                                                                                                                                                                                               |
| 매물 기록              | 매물의 기본·부가 정보, 사진, 자유 메모와 매물에 적용한 체크 기록을 아우르는 표현.                                                                                                                                                                                                |
| 시스템 제공 항목       | 서비스가 제공하는 체크 질문.<br>현장·계약 전 단계와 CORE·OPTIONAL 구분을 가진다.                                                                                                                                                                                                 |
| CORE / OPTIONAL        | 시스템 제공 항목의 핵심 및 선택 구분.                                                                                                                                                                                                                                            |
| 시스템 기본 체크리스트 | 해당 단계의 활성 CORE 항목으로 구성하는 기본 양식.                                                                                                                                                                                                                               |
| 사용자 체크리스트      | 사용자가 시스템 제공 항목을 선택하고 순서를 정해 만든 양식.                                                                                                                                                                                                                      |
| 매물 적용 체크리스트   | 특정 매물에 적용한 질문과 순서의 사본.                                                                                                                                                                                                                                           |
| 자유 메모 / 항목 메모  | 자유 메모는 매물에 포함된 매물 전체의 단일 기록이고, 항목 메모는 매물에 적용한 특정 체크 질문에 대한 기록이다.                                                                                                                                                                   |
| 체크 상태              | 항목별 미확인(UNCONFIRMED), 괜찮음(GOOD), 주의(CAUTION) 기록.                                                                                                                                                                                                                    |
| 진행 현황              | 적용된 체크 항목 가운데 얼마나 확인했는지를 보여주는 집계. GOOD과 CAUTION을 모두 확인 완료로봄.                                                                                                                                                                                  |
| 주변 분석              | 선택한 위치 주변의 시설과 거리를 조회해 보여주는 기능.                                                                                                                                                                                                                           |
| 비교 PDF               | 선택한 후보 매물의 저장된 정보와 기록을 비교할 수 있도록 구성한 PDF.                                                                                                                                                                                                             |

### 공통 삭제 정책

- 매물·사진·사용자 체크리스트 등 제품 데이터의 삭제는 모두 논리 삭제로 처리한다.
- DB 데이터와 저장소의 사진 파일은 물리 삭제하지 않는다. 삭제된 대상은 사용자 조회·사용 대상에서 제외한다.
- 매물을 삭제하면 해당 매물에 포함된 자유 메모와 연결된 사진·체크 기록은 목록·상세·사진 조회·비교 PDF 등에서 모두 제외한다. 자유 메모는 별도로 삭제하지 않는다.
- 사진을 개별 삭제하면 해당 사진을 조회·비교 PDF와 대표 사진 선정 대상에서 제외하되, 실제 사진 파일은 유지한다.
- 사용자 체크리스트를 삭제하면 양식의 조회·수정·신규 적용 대상에서 제외한다. 이미 매물에 적용된 질문과 기록은 유지한다.
