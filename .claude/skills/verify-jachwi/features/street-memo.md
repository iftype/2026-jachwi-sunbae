# 거리 메모

지도에서 자리를 골라 `좋아요` 또는 `싫어요` 평가와 메모를 남긴다. 남긴 평가는 나만 볼 수 있다. 사용방법의 영상 문구는 "정자동 지도에서 자리를 골라 좋아요와 함께 거리 메모를 남기기"다. 상태: 검증됨(2026-11-22, 데스크탑 1440x900, 실제 네이버 지도, 저장과 새로고침과 다른 회원 비공개와 삭제까지).

## Sub-features

- `memo-create` 지도 빈 곳 -> 메뉴 `이 위치에서`의 `메모 남기기` -> 패널 `이곳을 평가해 주세요`(`👍 좋아요`, `👎 싫어요`, `메모`, `취소`, `평가 남기기`).
- `memo-markers` 저장하면 그 자리에 마커 버튼(이름이 메모 글)이 생긴다. 지도 범위 안의 메모를 `GET /api/street-memos?minLatitude=..`로 불러 온다.
- `memo-details` 마커를 누르면 패널 `거리 메모`(평가, `내가 남긴 메모`, 메모 글, `메모 지우기`, `메모 닫기`).
- `memo-delete` `메모 지우기` -> `이 메모를 지울까요?` -> `지우기`.
- `memo-impression-log` 인상 기록 목록은 이번에 돌리지 않았다.

## How to get to it (user POV)

- 홈(`/`) 지도에서 빈 곳을 눌러 `메모 남기기`를 고른다. 데스크탑은 패널, 휴대폰은 시트로 열린다.
- 사용방법 화면 `/guide`의 `거리 메모 남기기` 데모.

## Driving it with Chrome DevTools MCP

Preconditions: doctor 통과, 네이버 키가 있는 `.env.local`, 새 `isolatedContext`.

- **열기.** `new_page http://localhost:3217/`(`isolatedContext: map` 등), `wait_for`로 `NAVER`를 기다리고 첫 방문 안내의 `확인`을 누른다.
- **자리 고르기.** [지도](./map.md)의 좌표 클릭 스니펫으로 빈 곳을 누른다. 스냅샷에 `menu "이 위치에서"`가 뜨면 `메모 남기기`를 누른다. 지도에 `메모 위치` 이미지가 생기고 패널이 열린다.
- **저장.** `👍 좋아요`를 누르고(누르기 전에는 `평가 남기기`가 비활성이다) `메모`에 `fill`한 뒤 `평가 남기기`. `POST /api/street-memos`가 201이고 본문은 `{latitude, longitude, memo, preference: "LIKE"}`, 응답은 `streetMemoId`, `isMine: true`, `adminDongCode`다. 마커 버튼이 생긴다.
- **증명.** 마커를 누르면 패널 `거리 메모`가 열린다. `reload` 뒤 `wait_for`로 메모 글을 기다려 마커가 남았는지 본다. 같은 주소를 다른 `isolatedContext`로 열어 같은 범위 조회에도 마커가 없는지 본다.
- **정리.** 마커 -> `메모 지우기` -> `지우기`. `DELETE /api/street-memos/<id>` 204.

## Gotchas

- 초안의 패널 문구 `이 장소를 평가해 주세요`는 폼 안의 라벨이고 패널 제목은 `이곳을 평가해 주세요`다. 두 번째 버튼은 `싫어요`다(초안은 `별로예요`).
- 첫 방문 안내(`이렇게 방을 기록해요. 빈 곳을 눌러 메모도 남겨요`)가 지도를 덮고 있으면 먼저 `확인`을 누른다.
- 다른 회원에게 안 보이는 것은 같은 범위 조회로 확인했다(`GET /api/street-memos` 200, 마커 없음).
- 이 기능을 돌리면 dev DB에 메모가 생긴다. 반드시 `메모 지우기`로 지운다. 익명 회원은 남는다.
- 증거 위치: `qa/runs/verify-jachwi/street-memo-20261122/`.
