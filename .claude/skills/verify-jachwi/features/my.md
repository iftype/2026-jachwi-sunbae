# 마이와 날씨

마이페이지(`/me`)의 `생활 날씨` 카드, 로그인 연결, 바로가기와, 홈 리스트 머리의 날씨 안내다. 상태: 검증됨(2026-11-25, 데스크탑 1440x900과 iPhone(WebKit), 웹에서 보이는 상태까지). 카드의 예보 그림은 앱(WebView) 전용이라 검증 못 함.

## Sub-features

- `my-weather-card` 영역 `생활 날씨`. 알림이 꺼져 있으면 `알림이 꺼져 있어요`, 토글 `알림 받기`, 상태 줄 `알림은 앱에서 받을 수 있어요.`(웹). 알림을 켜면 지금 기온, `<시>시 예보`, `오늘 최저 <n>° / 최고 <n>°`.
- `my-header-weather` 홈 리스트 머리의 `생활 날씨 안내` 안 영역 `<동네> 날씨`. 위치 권한이 있으면 `GET /api/weather/forecasts`로 지금 기온(`<n>°`)을 띄우고, 없으면 `위치 허용` 버튼이다.
- `my-shortcuts` `바로가기`(`체크리스트`, `방 비교`, `저렴한 한 끼`, `사용방법`), `로그인하고 동기화하기`(카카오, Apple), `회원 탈퇴`.

## How to get to it (user POV)

- 데스크탑: 왼쪽 `화면 이동`의 `마이`, 또는 머리의 `마이페이지` 링크.
- 휴대폰: 하단 탭 `마이`.

## 데스크탑과 iPhone(WebKit) 경로

- 실행(`qa`): `npm run test:iphone -- --device all my-weather`. 코드는 `qa/tests/<desktop|iphone>/my-weather.spec.ts`. 위치 권한을 준다.
- 경로:
  1. `마이`로 들어가면 주소가 `/me`이고 `생활 날씨` 카드에 `알림이 꺼져 있어요`와 상태 `알림은 앱에서 받을 수 있어요.`가 있다.
  2. 토글 `알림 받기`를 눌러도 꺼진 채이고 `PUT /api/members/me/notification-settings`를 보내지 않는다. 웹은 네이티브 푸시가 없어 켤 수 없다(`weatherPush.ts`의 `supportsNativePush`).
  3. 홈 리스트(휴대폰은 하단 탭 `내 기록` 뒤 `리스트`)로 가면 `GET /api/weather/forecasts`가 200이고 `<동네> 날씨` 영역에 기온 `<n>°`가 뜬다.
- 경로 끝에 우리 출처의 콘솔 오류와 실패한 요청이 0인지 본다. 스크린샷은 `my-weather-card.png`, `my-weather-header.png`다.

## 검증 못 함

- 알림을 켠 뒤 카드의 예보 그림(지금 기온, 최저와 최고). 앱(WebView)의 네이티브 푸시 다리가 있어야 켜지고, 이 노트북에는 앱을 구동할 수단이 없다. 목은 예보(맑음, 최저 16도, 최고 23도)를 주므로 앱에서 돌리면 그 값이 보여야 한다.

## Gotchas

- 휴대폰 홈은 지도 보기로 열린다. 날씨 안내는 리스트 보기 머리에만 있다.
- 데스크탑에는 같은 `생활 날씨 안내`가 화면 밖 동네 찾기 칸에 하나 더 있다. 보이는 것만 고른다(역할 선택자는 숨은 요소를 고르지 않는다).
- 목의 알림 설정은 서버를 새로 띄우면 꺼진 상태로 돌아간다.
