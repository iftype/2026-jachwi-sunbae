# 자취선배 검증 지도

사용자 눈에 보이는 기능 5개의 구동 레시피다. 노션 기능별 변천 페이지와 같은 단위다. 먼저 이 색인을 읽고, 해당 기능 파일을 레시피로 쓴다.

## 기준 상태

- `scripts/launch.sh 3217`로 로컬 프론트를 띄우고 `scripts/doctor.sh 3217`이 통과한다.
- 드라이버는 Chrome DevTools MCP다. 지도는 `frontend/.env.local`에 네이버 키가 있으면 실제 지도, 없으면 `DEMO MAP`이다.
- 새 브라우저 컨텍스트(`new_page`의 `isolatedContext`)는 새 익명 회원이다. 샘플 매물 `(미리보기) 코엑스 근처`(`/properties/-1`)가 있다.
- 우리가 띄운 인스턴스가 아니면 구동하지 않는다.

## 구동 규칙

- ARIA 이름을 선택자로 쓴다. uid는 스냅샷마다 바뀐다.
- 동네 찾기 결과 스냅샷은 파일로 저장한다(동네 수백 개).
- 증거는 `qa/runs/verify-jachwi/<기능>-<날짜>/`에 둔다. 형식은 SKILL.md의 Evidence 절이다.
- 닿을 수 없는 경로는 시도한 명령과 빠진 전제를 보고한다. 다른 경로로 검증한 것처럼 쓰지 않는다.
- 각 파일의 상태 줄이 `초안`이면 코드와 화면 스냅샷에서 뽑은 레시피이고 끝까지 돌려 본 적이 없다. 처음 돌릴 때 고치고 `검증됨`으로 바꾼다.
- 지도 빈 곳을 누르는 일(거리 메모, 매물 등록)은 [지도](./map.md)의 좌표 클릭 스니펫을 쓴다.

## 기능

- [동네 찾기](./neighborhood-finder.md) 통근 시간과 월세로 동네를 찾는다. 상태: 검증됨(2026-11-22, 데스크탑, 실제 지도와 DEMO)
- [지도](./map.md) 홈의 본 방 기록 지도, 주소 검색, 동네 필터, 시설 카테고리. 상태: 검증됨(2026-11-22, 데스크탑)
- [매물 상세](./property-detail.md) 매물 정보 탭, 새 매물 만들기와 수정과 삭제. 상태: 검증됨(2026-11-22, 데스크탑)
- [체크리스트](./checklist.md) 매물별 체크와 집계, 내 체크리스트. 상태: 검증됨(2026-11-22, 데스크탑, 새 체크리스트 만들기 제외)
- [거리 메모](./street-memo.md) 지도에서 자리를 골라 평가와 메모를 남기고 지운다. 상태: 검증됨(2026-11-22, 데스크탑)
