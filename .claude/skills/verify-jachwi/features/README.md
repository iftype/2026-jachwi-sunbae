# 자취선배 검증 지도

사용자 눈에 보이는 기능의 구동 레시피다. 노션 기능별 변천 페이지와 같은 단위다. 먼저 이 색인을 읽고, 해당 기능 파일을 레시피로 쓴다.

## 기준 상태

- `scripts/launch.sh 3217`로 로컬 프론트를 mock으로 띄우고 `scripts/doctor.sh 3217`이 통과한다.
- 드라이버는 Chrome DevTools MCP다. 지도는 `frontend/.env.local`에 네이버 키가 있으면 실제 지도, 없으면 `DEMO MAP`이다.
- 새 브라우저 컨텍스트(`new_page`의 `isolatedContext`)는 새 익명 회원이다. 샘플 매물 `(미리보기) 코엑스 근처`(`/properties/-1`)가 있다.
- 우리가 띄운 인스턴스가 아니면 구동하지 않는다.

## 구동 규칙

- ARIA 이름을 선택자로 쓴다. uid는 스냅샷마다 바뀐다.
- 동네 찾기 결과 스냅샷은 파일로 저장한다(동네 수백 개).
- 증거는 `qa/runs/verify-jachwi/<기능>-<날짜>/`에 둔다. 형식은 SKILL.md의 Evidence 절이다.
- 닿을 수 없는 경로는 시도한 명령과 빠진 전제를 보고한다. 다른 경로로 검증한 것처럼 쓰지 않는다.
- 각 파일의 상태 줄이 `초안`이면 코드와 화면 스냅샷에서 뽑은 레시피이고 끝까지 돌려 본 적이 없다. 처음 돌릴 때 고치고 `검증됨`으로 바꾼다.
- 지도 빈 곳을 누르는 일(거리 메모, 매물 등록)은 [지도](./map.md)의 좌표 클릭 스니펫을 쓴다.
- 휴대폰 경로는 각 기능 파일의 "iPhone(WebKit) 경로"다. `cd qa && npm run test:iphone` 한 번으로 전부 돈다(SKILL.md의 "iPhone(WebKit)과 데스크탑 경로 검증").
- 데스크탑 경로(Chromium 1440x900)는 `npm run test:desktop`, 둘 다는 `npm run test:iphone -- --device all`이다. 같은 운영 빌드와 목으로 돈다.

## 검증 못 함

| 곳                 | 이유                                                                                                                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 관리자(`/admin/*`) | 첫 화면 `관리자 접속`(접속 코드 입력)까지만 뜬다(2026-11-25 확인). 코드 확인과 대시보드는 `/api/admin/...`인데 목에 핸들러가 없고, 접속 코드는 운영 비밀이라 dev API로도 돌리지 않는다. |
| 앱(WebView)        | 앱을 구동할 수단(시뮬레이터나 기기)이 이 노트북에 없다. 네이티브 다리가 있어야 하는 동작(날씨 알림 켜기와 카드 예보, 네이티브 로그인, 푸시)은 웹 경로로 대신하지 않는다.                |
| 사진 올리기        | 목이 일부러 501로 답한다([매물 사진](./property-photos.md)).                                                                                                                            |
| 툴팁 Esc 닫기      | 앱 화면에서 쓰는 곳이 없다([머지로 생기는 동작](./merge-behaviors.md)).                                                                                                                 |
