# 지도

홈(`/`)은 본 방 기록 지도다. 지도 위에 기록한 매물 마커, 시설 카테고리, 동네별 필터가 있고 왼쪽에 리스트가 붙는다. 상태: 초안. 화면 구조는 스냅샷으로 확인했고 아래 조작은 아직 끝까지 돌리지 않았다.

## Sub-features

- `map-markers` 기록한 매물이 지도 마커와 리스트 카드로 같이 보인다.
- `map-address-search` `주소 검색`으로 지도를 옮긴다.
- `map-facility-layers` `교통 표시하기`, `편의점 표시하기`, `병원 표시하기`, `중개업소 표시하기`.
- `map-dong-filter` `기록한 동네`의 `전체`와 구 이름 버튼.
- `map-zoom-locate` `지도 확대`, `지도 축소`, `현재 위치로 이동`.

## How to get to it (user POV)

- 주소창 `/`. `/map`과 `/properties`는 `/`로 넘어간다.
- 이동 바의 `내 기록`.

## Driving it with Chrome DevTools MCP

Preconditions: doctor 통과, 새 익명 회원.

- **열기.** `new_page http://localhost:3217/`. `기록을 불러오는 중이에요.`가 사라질 때까지 `wait_for`로 `본 방 기록`을 기다린다. 로딩 중 스냅샷은 뼈대만 있다.
- **마커와 리스트.** `모든 기록` 영역에 `(미리보기) 코엑스 근처`(보증금 3,000만원 / 월세 55만원, 서울 강남구 영동대로 513)가 있고, 지도에 같은 이름의 버튼 마커가 있다. 둘 다 있어야 한다.
- **카테고리.** `편의점 표시하기`를 누르고 스냅샷에서 눌림 상태와 새 마커를 본다.
- **증명.** 스크린샷과 스냅샷 파일, 마커를 눌러 `/properties/-1`로 가는 주소 변화.

## Gotchas

- 샘플 매물은 회원이 직접 만든 기록이 없을 때 보이는 미리보기다. 실제 기록 저장 검증은 매물 상세 문서의 저장 경로를 따른다.
- DEMO MAP에서 시설 카테고리가 실제 데이터인지 시안인지 확인되지 않았다. 처음 돌릴 때 네트워크 호출로 판단한다.
- 휴대폰은 `RecordsMobilePage`라 리스트와 지도가 `리스트`, `지도` 토글로 나뉜다.
