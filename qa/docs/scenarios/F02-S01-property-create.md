# F02-S01 정상 매물 등록 후 재조회

| 항목      | 내용                                                          |
| --------- | ------------------------------------------------------------- |
| Flow      | [F02 후보 매물 등록](../user-flows/F02-property-create.md)    |
| 근거      | `AC-PROP-003`, `REQ-PROP-009`, `REQ-PROP-004`, `REQ-PROP-006` |
| 상태      | 자동화                                                        |
| 실행 방식 | 수동, 자동(`qa/tests/F02-S01-property-create.spec.ts`)        |

## 목적

필수 정보만으로 매물을 등록하면 생성한 매물의 상세로 이동하고, 입력한 이름과 금액이 새로고침 후에도 그대로 유지되는지 확인한다.

## 사전 조건

- DEV 프론트엔드와 API에 접속할 수 있다.
- 쿠키·저장소가 비어 있는 새 브라우저 세션이다.
- 새 닉네임 `qa-{runId}`로 비밀번호 없이 시작해 빈 매물 목록에 있다.

## 테스트 데이터

| 항목      | 값                            |
| --------- | ----------------------------- |
| 닉네임    | `qa-{runId}`                  |
| 매물 이름 | `F02-S01 {runId}`             |
| 보증금    | `500` (만원)                  |
| 월세      | `50` (만원)                   |
| 주소      | 고르지 않는다(기본 위치 적용) |
| 부가 정보 | 입력하지 않는다               |

## 단계

1. 매물 목록에서 매물 등록 화면으로 이동한다.
2. 보증금과 월세를 입력한다.
3. 주소는 고르지 않고 다음 단계로 진행한다.
4. 이름 입력란을 선택해 매물 이름을 입력하고, 부가 정보 없이 등록한다.
5. 이동한 화면을 확인한다.
6. 브라우저를 새로고침하고 화면을 다시 확인한다.
7. 매물 목록으로 이동한다.

## 판정 메모

- 금액 표기 형식(`500만원`, `5,000,000원` 등)은 명세가 정하지 않았다. 표기를 해석할 수 있으면 금액을 비교해 같으면 `PASS`, 다르면 `FAIL`이다. 표기를 해석할 수 없을 때만 `NEEDS_REVIEW`다. ([DL-001](../decision-log/DL-001-amount-mismatch-fail.md))
- API 응답의 금액 단위(만원·원)도 명세가 정하지 않았다. 입력값과 같은 금액으로 해석되는지만 본다.
- 새 회원이므로 목록에 2건 이상 보이면 중복 등록으로 E4 `FAIL`이다.
- 이 Scenario에서 판정하지 않는 것: 주소 기본값(`AC-MAP-003`), 체크리스트 자동 적용(`AC-PROP-007`), 이름 초기값 `새 매물`(`AC-PROP-001`). 이상이 보이면 Run Report의 기타 관찰에 남긴다.
