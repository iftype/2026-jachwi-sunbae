# F02-S03 주소를 고르지 않은 등록의 기본 위치

| 항목      | 내용                                                                    |
| --------- | ----------------------------------------------------------------------- |
| Flow      | [F02 후보 매물 등록](../user-flows/F02-property-create.md)              |
| 근거      | `AC-MAP-003`, `AC-PROP-005`, `POL-MAP-001`, `POL-MAP-002`               |
| 상태      | 자동화                                                                  |
| 실행 방식 | 수동, 자동(`qa/tests/F02-S03-property-create-default-location.spec.ts`) |

## 목적

마지막으로 본 지도 위치가 없는 사용자가 주소를 고르지 않고 매물을 등록하면, 위치 권한을 묻지 않고 우테코 판교 사옥의 주소와 위치가 저장되는지 확인한다.

## 사전 조건

- DEV 프론트엔드와 API에 접속할 수 있다.
- 쿠키와 저장소가 비어 있는 새 브라우저 세션이다. 지도를 연 적이 없어 마지막으로 본 지도 위치가 없다.
- 새 닉네임 `qa-{runId}`로 비밀번호 없이 시작해 빈 매물 목록에 있다.
- 기본 위치의 주소 변환 요청(`GET /api/maps/reverse-geocode`)이 성공한다. 이 요청이 실패하면 외부 주소 API 장애일 수 있으므로 `BLOCKED`다. 주소 변환 실패 시의 대체 동작(`REQ-MAP-004`)은 이 Scenario에서 판정하지 않는다.

## 테스트 데이터

| 항목                | 값                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------- |
| 매물 이름           | `F02-S03 {runId}`                                                                       |
| 보증금, 월세        | `500`, `50` (만원)                                                                      |
| 주소                | 고르지 않는다                                                                           |
| 판교 사옥 주소      | 금토로80번길 40 (`POL-MAP-002`)                                                         |
| 판교 사옥 기준 좌표 | 위도 37.406401604461735, 경도 127.08884281061177. 위 주소의 좌표로 사람이 확인한 값이다 |
| 위치 허용 오차      | 기준 좌표에서 100m 이내                                                                 |

## 단계

1. 매물 목록에서 매물 등록 화면으로 이동한다.
2. 보증금과 월세를 입력하고 위치 단계로 진행한다.
3. 위치 단계에 표시된 기본 주소를 확인한다. 주소는 고르지 않고 다음 단계로 진행한다.
4. 매물 이름을 입력하고 등록한다.
5. 브라우저를 새로고침하고 상세 화면의 주소를 확인한다.

## 판정 메모

- 주소는 `금토로80번길 40`이 들어 있으면 일치로 본다. 시, 구 표기와 띄어쓰기 차이는 판정하지 않는다.
- 주소 문자열이 다르더라도 좌표가 기준 좌표에서 100m 이내이면 같은 곳을 다르게 표기했을 수 있으므로 E2는 `NEEDS_REVIEW`로 넘긴다. 좌표도 100m를 넘으면 `FAIL`이다.
- 위치 권한 요청은 브라우저의 위치 조회 호출(`getCurrentPosition`, `watchPosition`)로 확인한다.
- 이 Scenario에서 판정하지 않는 것: 마지막으로 본 지도 위치가 있을 때의 기본 위치, 매물 수정 화면, 주소 변환 실패 시의 대체 동작, 현재 위치 버튼.
