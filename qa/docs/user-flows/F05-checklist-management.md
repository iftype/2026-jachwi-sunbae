# F05 체크리스트 준비

| 항목        | 내용                                                               |
| ----------- | ------------------------------------------------------------------ |
| 사용자 목적 | 집을 볼 때 확인할 질문을 내 기준에 맞게 미리 고르고 순서를 정한다. |
| 진입점      | 체크리스트 관리 화면                                               |
| 선행 Flow   | F01                                                                |
| 관련 명세   | [체크리스트](../../../docs/product/specs/checklist.md)             |

## 핵심 흐름

1. 현장 또는 계약 전 단계를 고른다.
2. 새 사용자 체크리스트를 만든다. 해당 단계의 활성 CORE 항목이 초기 구성으로 들어 있다.
3. 검색으로 제공 항목을 찾아 추가하고, CORE를 포함한 항목을 빼고, 전체 순서를 정한다.
4. 이름을 정해 저장한다.
5. 저장한 양식을 다시 조회·수정하거나 삭제한다.

## 관련 요구사항

| ID              | 확인할 점                                  |
| --------------- | ------------------------------------------ |
| `REQ-CHECK-001` | 현장·계약 전 단계 구분                     |
| `REQ-CHECK-002` | CORE·OPTIONAL 구분, 활성 항목 제공         |
| `REQ-CHECK-003` | 검색어로 제공 항목 추가                    |
| `REQ-CHECK-004` | 사용자 체크리스트 생성·조회·수정·논리 삭제 |
| `REQ-CHECK-005` | 생성 시 활성 CORE를 초기 구성으로 제공     |
| `REQ-CHECK-006` | 이름·항목 포함 여부·순서 변경 저장         |
| `REQ-CHECK-007` | CORE도 제거 가능                           |

## 관련 인수 기준

`AC-CHECK-001`, `AC-CHECK-002`, `AC-CHECK-006`

## Scenario

아직 작성하지 않았다.

## QA 메모

- 사용자 체크리스트 변경·삭제 흐름과 제공 질문 목록은 [미정 영역](../source-of-truth.md#4-미정-영역)이다.
