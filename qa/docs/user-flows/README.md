# 사용자 흐름

- 상태: v0.1 / 작성일: 2026-10-06

사용자가 자취선배에서 **무엇을 달성하려는지**를 목적 단위로 나눈다. 기능 하나나 API 하나가 아니라 사용자 목적 하나가 Flow 하나다. 같은 목적 안의 여러 상황(성공, 실패, 권한 등)은 [Scenario](../scenarios/README.md)로 나눈다.

## 전체 여정

```text
F01 닉네임으로 시작·복귀
 │
 ▼
F02 후보 매물 등록 ◀── 체크리스트 자동 적용 ── F05 체크리스트 준비
 │                                              │
 ▼                                              │ 양식 적용·교체
F03 매물 정보 관리                               ▼
 ├── F04 사진 기록 관리                    F06 매물 체크 기록
 ├── F06 매물 체크 기록
 └── F07 위치·주변 분석
 │
 ▼  여러 후보에 반복
F08 매물 비교
```

## Flow 문서 형식

각 Flow 문서는 다음 순서로 작성한다. 명세 내용을 복사하지 않고 ID로 연결한다.

1. 요약 표: 사용자 목적, 진입점, 선행 Flow, 관련 명세
2. 핵심 흐름: 사용자 행동 순서
3. 관련 요구사항: 이 Flow에서 확인할 `REQ` ID와 짧은 이름
4. 관련 인수 기준: 이 Flow의 Scenario 후보가 되는 `AC` ID
5. Scenario: 작성한 Scenario 목록
6. QA 메모: 미정 영역, 자동화 시 주의할 점(있을 때만)

모든 `REQ` ID는 하나 이상의 Flow에 배정한다. 여러 Flow에 걸친 요구사항은 각 Flow에 모두 적는다.
