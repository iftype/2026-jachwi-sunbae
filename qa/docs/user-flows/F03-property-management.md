# F03 매물 정보 관리

| 항목        | 내용                                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 사용자 목적 | 저장한 후보의 정보를 다시 보고, 바뀐 내용을 고치고, 생각을 메모로 남기고, 필요 없어진 후보를 지운다.                                                          |
| 진입점      | 매물 목록, 매물 상세                                                                                                                                          |
| 선행 Flow   | F02                                                                                                                                                           |
| 관련 명세   | [매물](../../../docs/product/specs/property.md), [지도](../../../docs/product/specs/map.md), [공통 삭제 정책](../../../docs/product/README.md#공통-삭제-정책) |

## 핵심 흐름

1. 매물 목록에서 각 매물의 이름·주소·금액·대표 사진·현장 체크 진행 현황을 확인한다. 최근 등록한 매물이 위에 있다.
2. 매물 상세에서 기본·부가 정보, 사진, 자유 메모, 체크 진행 현황을 확인한다.
3. 기본·부가 정보를 수정한다. 위치는 수정 중 선택한 위치, 저장된 위치 순으로 시작한다.
4. 자유 메모를 정보 수정과 별도로 저장한다.
5. 매물을 삭제하려 하면 되돌릴 수 없다는 안내를 보고 확정하거나 취소한다.

## 관련 요구사항

| ID             | 확인할 점                                   |
| -------------- | ------------------------------------------- |
| `REQ-PROP-001` | 자신의 매물 조회·수정·삭제                  |
| `REQ-PROP-004` | 목록의 이름·주소·금액·대표 사진·진행 현황   |
| `REQ-PROP-005` | 목록 정렬 순서                              |
| `REQ-PROP-006` | 상세의 기본·부가 정보, 사진·메모, 진행 현황 |
| `REQ-PROP-007` | 삭제 전 안내와 취소                         |
| `REQ-PROP-008` | 부가 정보 수정                              |
| `REQ-PROP-011` | 매물 자유 메모 조회·수정                    |
| `REQ-MAP-005`  | 선택한 주소·좌표를 수정 폼에 전달           |
| `REQ-MAP-008`  | 위치 수정의 시작 위치                       |

## 관련 인수 기준

- 매물: `AC-PROP-004`, `AC-PROP-006`, `AC-PROP-008` ~ `AC-PROP-010`
- 지도: `AC-MAP-003`, `AC-MAP-004`

## QA 메모

- 삭제는 논리 삭제다. 삭제한 매물과 종속 기록이 목록·상세·사진·새 PDF에서 모두 빠지는지 함께 본다.
