# F02 후보 매물 등록

| 항목        | 내용                                                                                                                                                |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 사용자 목적 | 새로 발견한 집을 나중에 다시 보고 비교할 수 있도록 저장한다.                                                                                        |
| 진입점      | 매물 목록의 매물 추가                                                                                                                               |
| 선행 Flow   | F01                                                                                                                                                 |
| 관련 명세   | [매물](../../../docs/product/specs/property.md), [지도](../../../docs/product/specs/map.md), [체크리스트](../../../docs/product/specs/checklist.md) |

## 핵심 흐름

1. 매물 등록 화면을 연다. 이름에는 `새 매물`이 채워져 있다.
2. 이름, 보증금, 월세(만원 단위)를 입력한다.
3. 주소를 검색해 결과를 고르거나 지도에서 위치를 고른다. 고르지 않으면 마지막으로 본 위치 또는 판교 사옥이 적용된다.
4. 필요하면 부가 정보(입주 가능일, 방 옵션, 관리비, 방문 일정, 확인한 곳)를 입력한다.
5. 등록하면 생성한 매물의 상세 화면으로 이동한다.
6. 현장·계약 전 체크리스트가 자동 적용되어 모든 항목이 미확인 상태다.

## 관련 요구사항

| ID                 | 확인할 점                                    |
| ------------------ | -------------------------------------------- |
| `REQ-PROP-001`     | 자신의 매물 등록                             |
| `REQ-PROP-002`     | 이름·보증금·월세 필수, 이름 초기값 `새 매물` |
| `REQ-PROP-003`     | 위치 선택 또는 주소 검색, 미입력 시 기본값   |
| `REQ-PROP-008`     | 부가 정보 입력                               |
| `REQ-PROP-009`     | 등록 후 상세 이동, 재진입 시 저장 정보 유지  |
| `REQ-PROP-010`     | 등록 시 두 단계 체크리스트 자동 적용         |
| `REQ-MAP-002`      | 위치 조회 실패 시 판교 사옥 사용             |
| `REQ-MAP-004`      | 지도에서 고른 좌표의 주소 확인               |
| `REQ-MAP-005`      | 선택한 주소·좌표를 등록 폼에 전달            |
| `REQ-MAP-008`      | 신규 위치 선택의 시작 위치                   |
| `REQ-MAP-011`      | 위치 선택 중 현재 위치로 이동                |
| `REQ-CHECK-012`    | 최근 적용 양식 또는 기본 양식 자동 적용      |
| `REQ-PROGRESS-002` | 신규 매물의 항목은 미확인·빈 메모로 시작     |

## 관련 인수 기준

- 매물: `AC-PROP-001` ~ `AC-PROP-005`, `AC-PROP-007`, `AC-PROP-011`
- 지도: `AC-MAP-003`, `AC-MAP-004`
- 체크리스트 자동 적용: `AC-CHECK-003` ~ `AC-CHECK-005`

## QA 메모

- 주소 검색과 좌표의 주소 변환은 외부 공공데이터 API를 쓴다. 외부 API 장애로 막히면 `FAIL`이 아니라 `BLOCKED`다.
- 체크리스트 자동 적용(`AC-CHECK-004`, `AC-CHECK-005`)은 F05·F06으로 양식을 준비해야 확인할 수 있다.
