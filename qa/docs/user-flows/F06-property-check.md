# F06 매물 체크 기록

| 항목        | 내용                                                                                                      |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| 사용자 목적 | 집을 보며 질문별로 확인 결과와 메모를 남기고, 얼마나 확인했는지 본다. 현장·계약 전 두 단계 모두 해당한다. |
| 진입점      | 매물 상세의 체크리스트                                                                                    |
| 선행 Flow   | F02. 양식을 교체하려면 F05                                                                                |
| 관련 명세   | [체크리스트](../../../docs/product/specs/checklist.md)                                                    |

## 핵심 흐름

1. 매물에 적용된 체크리스트를 연다. 등록 시 자동 적용되어 있다.
2. 필요하면 시스템 기본 체크리스트나 내 사용자 체크리스트로 교체한다. 두 양식에 공통인 질문의 결과는 유지된다.
3. 항목마다 상태(미확인·괜찮음·주의)를 고른다. 고르는 즉시 저장된다.
4. 항목 메모를 쓰고 저장 버튼으로 저장한다.
5. 진행 현황을 확인한다. 매물 상세와 목록에도 현장 체크 집계가 보인다.

## 관련 요구사항

| ID                 | 확인할 점                                   |
| ------------------ | ------------------------------------------- |
| `REQ-CHECK-008`    | 기본 또는 사용자 양식 적용·교체             |
| `REQ-CHECK-009`    | 기본 양식 적용 시 활성 CORE 복사            |
| `REQ-CHECK-010`    | 사용자 양식 적용 시 매물 전용 기록으로 복사 |
| `REQ-CHECK-011`    | 교체 시 공통 질문 결과 승계                 |
| `REQ-PROGRESS-001` | 상태는 미확인·괜찮음·주의                   |
| `REQ-PROGRESS-002` | 신규 항목은 미확인·빈 메모로 시작           |
| `REQ-PROGRESS-003` | 상태는 즉시, 메모는 저장 버튼으로 독립 저장 |
| `REQ-PROGRESS-004` | 전체·완료·괜찮음·주의·미확인 수 제공        |
| `REQ-PROGRESS-005` | 매물 상세의 현장 집계                       |
| `REQ-PROGRESS-006` | 매물 목록의 현장 집계                       |

## 관련 인수 기준

`AC-CHECK-006` ~ `AC-CHECK-008`, `AC-PROP-007`
