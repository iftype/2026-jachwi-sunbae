# F07 위치·주변 분석

| 항목        | 내용                                                                     |
| ----------- | ------------------------------------------------------------------------ |
| 사용자 목적 | 후보 집들의 위치를 지도에서 보고, 집 주변에 어떤 시설이 있는지 확인한다. |
| 진입점      | 일반 지도, 매물의 주변 분석                                              |
| 선행 Flow   | F02                                                                      |
| 관련 명세   | [지도](../../../docs/product/specs/map.md)                               |

## 핵심 흐름

1. 일반 지도를 연다. 마지막으로 본 위치(없으면 판교 사옥)에서 시작하고, 진입만으로는 위치 권한을 묻지 않는다.
2. 필요하면 현재 위치 버튼으로 내 위치로 이동한다. 위치 조회에 실패하면 판교 사옥을 보여준다.
3. 내 매물 핀을 고르면 해당 매물을 기준으로 주변 시설을 조회하고 하단에 매물 카드 하나를 표시한다. 지도 빈 곳을 누르면 선택을 해제한다.
4. 조회 반경을 고른다. 최초 진입에는 비활성화하며 매물·주소·현재 위치 선택 또는 매물 추가 진입 후 활성화한다. 500m·1km·2km는 각각 지도 레벨 5·6·7로 바뀌며, 선택 매물이 있다면 그 매물을 기준으로 화면을 다시 맞춘다.
5. 시설 카테고리(병원·교통·학교·편의점·중개사무소)를 하나 고른다. 처음에는 미선택이고, 같은 카테고리를 다시 누르면 해제된다.
6. 시설 핀·목록·개수를 확인한다. 매물 핀은 카테고리와 관계없이 계속 보인다.

## 관련 요구사항

| ID            | 확인할 점                              |
| ------------- | -------------------------------------- |
| `REQ-MAP-001` | 사용자 조작 시에만 현재 위치 요청·표시 |
| `REQ-MAP-002` | 위치 조회 실패 시 판교 사옥 사용       |
| `REQ-MAP-003` | 매물 핀 확인, 주변 분석으로 이동       |
| `REQ-MAP-006` | 주변 조회 반경 선택                    |
| `REQ-MAP-007` | 시설 카테고리별 조회 결과와 개수       |
| `REQ-MAP-008` | 주변 분석의 시작 위치                  |
| `REQ-MAP-009` | 시설 필터는 한 번에 한 카테고리        |
| `REQ-MAP-010` | 최초 진입 시 카테고리 미선택           |

## 관련 인수 기준

`AC-MAP-001`, `AC-MAP-002`, `AC-MAP-005` ~ `AC-MAP-007`

## Scenario

아직 작성하지 않았다.

## QA 메모

- 시설 개수 상한, 주소 출처 표시, 버스정류장 조회 반경은 [미정 영역](../source-of-truth.md#4-미정-영역)이다.
- 위치 권한, 지도 SDK, 외부 시설·주소 API에 의존한다. 외부 장애로 확인하지 못하면 `BLOCKED`다.
- 매물 추가 중에는 중앙 핀을 옮겨 반경과 시설 카테고리를 확인할 수 있다. 일반 지도 이동은 시설 조회 기준을 바꾸지 않는다.
- 시트는 조회 전에도 손잡이를 표시하고 펼친 내용만 로딩·오류·빈 목록으로 구분한다. 드래그 중에도 내용을 표시하며 카드 목록은 하단 탭 위에서만 스크롤된다.
