# F08 매물 비교

| 항목        | 내용                                                           |
| ----------- | -------------------------------------------------------------- |
| 사용자 목적 | 여러 후보의 기록을 한 문서로 나란히 보고 최종 선택을 판단한다. |
| 진입점      | 매물 목록의 비교 선택                                          |
| 선행 Flow   | F02. 비교할 기록은 F03·F04·F06                                 |
| 관련 명세   | [매물 비교·PDF](../../../docs/product/specs/compare.md)        |

## 핵심 흐름

1. 비교할 내 매물을 2~5개 골라 순서를 정한다.
2. 비교 PDF를 만들어 내려받는다.
3. PDF 첫 부분에서 선택 순서대로 기본 정보와 단계별 체크 집계를 비교한다.
4. 매물별 상세에서 기본·부가 정보, 사진, 자유 메모, 체크 기록을 확인한다.

## 관련 요구사항

| ID                | 확인할 점                                   |
| ----------------- | ------------------------------------------- |
| `REQ-COMPARE-001` | 2~5개 선택, PDF 다운로드                    |
| `REQ-COMPARE-002` | 선택 순서 유지                              |
| `REQ-COMPARE-003` | 첫 부분의 기본 정보·체크 집계 비교          |
| `REQ-COMPARE-004` | 매물별 상세 기록 포함                       |
| `REQ-COMPARE-005` | 다른 회원·삭제 매물과 삭제·제외 기록 미포함 |

## 관련 인수 기준

`AC-COMPARE-001` ~ `AC-COMPARE-006`

## Scenario

아직 작성하지 않았다.

## QA 메모

- 명세상 매물 비교는 최후순위다.
- PDF 내용 확인은 텍스트 추출과 매물 재조회 결과 비교가 필요하다. 다른 매물의 기록이 섞였는지 판단하는 데 AI를 활용할 수 있다.
