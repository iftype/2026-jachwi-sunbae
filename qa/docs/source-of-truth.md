# QA 정답 기준

- 상태: v0.1 / 작성일: 2026-10-06

QA를 실행하는 사람과 AI가 **무엇을 정답으로 믿고, 무엇을 검증 대상으로 볼지** 정한다. Expected와 판정은 이 문서의 기준을 따른다.

## 1. 정답 근거

아래 문서만 기대 동작의 근거로 사용한다.

| 순위 | 문서                                                        | 역할                                                                                    |
| ---- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 1    | [`docs/product/specs/`](../../docs/product/specs/README.md) | 제품 동작의 정본. 요구사항(`REQ`)·정책(`POL`)·인수 기준(`AC`)을 정한다.                 |
| 1    | [`docs/product/README.md`](../../docs/product/README.md)    | 공통 용어와 공통 삭제 정책. 기능 명세와 같은 효력을 가진다.                             |
| 2    | `qa/README.md`, `qa/docs/`                                  | 명세를 **어떻게 시험하고 판정할지** 정한다. 명세에 없는 제품 규칙을 새로 만들지 않는다. |

`qa/docs/scenarios/`의 Scenario가 명세와 다르면 명세를 따르고 Scenario를 고친다.

## 2. 검증 대상

다음은 정답 근거가 아니라 **검증 대상**이다. "현재 그렇게 동작한다"는 기대 동작의 근거가 될 수 없다.

- 프론트엔드, 백엔드, 모바일 코드와 현재 DEV의 동작
- 각 파트 문서(`frontend/docs/`, `backend/docs/`)
- 단위 및 통합 테스트, MSW fixture
- Swagger(OpenAPI): API 경로 및 필드처럼 **어디를 관찰할지** 찾는 참고로만 사용한다.
- Notion 등 저장소 밖 문서

## 3. 판정 규칙

1. Expected는 명세 ID에서 나온다. 모든 Expected에 근거 ID(`AC`·`REQ`·`POL`)를 적는다.
2. **위반한 명세 ID를 지목할 수 있을 때만 `FAIL`이다.** 지목할 수 없으면 기대와 달라도 `NEEDS_REVIEW`다.
3. 명세가 정하지 않았거나 [미정 사항](#4-미정-영역)에 해당하는 동작은 `NEEDS_REVIEW`로 사람에게 넘긴다.
4. 명세끼리 충돌하면 `NEEDS_REVIEW`로 두고 충돌한 ID를 함께 기록한다.
5. QA는 명세를 고치지 않는다. 명세가 틀리거나 부족해 보이면 사람 판정 `SPEC_GAP`으로 넘기고, 제품 결정 후 명세를 별도로 수정한다.

판정값과 사람 판정값은 [QA 실행 결과 형식](report-schema.md#4-판정)에서 정의한다.

## 4. 미정 영역

다음 영역은 명세가 아직 정하지 않았다. 이 영역의 동작은 `FAIL`로 판정하지 않는다. 최신 내용은 각 명세의 미정 사항 절을 따른다.

| 영역       | 미정 내용                                                                       | 명세                                                                        |
| ---------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 인증       | 로그인 유지 시간, 자동 갱신, 새로고침·새 탭·재시작 시 유지 범위, 만료 처리      | [authentication.md](../../docs/product/specs/authentication.md#5-미정-사항) |
| 매물       | 저장 연속 클릭 등 실패 처리                                                     | [property.md](../../docs/product/specs/property.md#5-미정-사항)             |
| 사진       | 세부 실패 상황                                                                  | [photo.md](../../docs/product/specs/photo.md#5-미정-사항)                   |
| 지도       | 시설 개수 상한(임시 기준 카테고리별 45개), 주소 출처 표시, 버스정류장 조회 반경 | [map.md](../../docs/product/specs/map.md#5-미정-사항)                       |
| 체크리스트 | 사용자 체크리스트 변경·삭제 흐름, 제공 질문 목록                                | [checklist.md](../../docs/product/specs/checklist.md#5-미정-사항)           |
